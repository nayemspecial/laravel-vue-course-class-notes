**প্লাটফর্ম:** প্রযুক্তিপ্লাস একাডেমী (ProjuktiPlus Academy)

**বিষয়:** ১০.২ ড্যাশবোর্ড কন্ট্রোলার তৈরি করা, রাউট সেটআপ করা, কন্ট্রোলারে লজিক যুক্ত করা, ডাটাবেজ থেকে মোট পোস্টের সংখ্যা গণনা, ভিউ ফাইলে ডাটা পাঠানো, ড্যাশবোর্ডে ডায়নামিক ডাটা প্রদর্শন।

**প্রযুক্তি প্লাস একাডেমির** পক্ষ থেকে আপনাদের সবাইকে স্বাগতম জানাচ্ছি। আজকের পর্বে আমরা লারাভেলে সরাসরি রাউটে ভিউ রিটার্ন না করে, একটি ডেডিকেটেড অ্যাডমিন ড্যাশবোর্ড কন্ট্রোলার তৈরি করব এবং ডাটাবেজ থেকে মোট পোস্টের সংখ্যা গণনা (Count) করে ড্যাশবোর্ডে ডায়নামিকালি প্রদর্শন করা শিখব।

নিচে ধাপভিত্তিক সম্পূর্ণ কোড এবং বিস্তারিত ব্যাখ্যা দেওয়া হলো:

---

## ১. ড্যাশবোর্ড কন্ট্রোলার তৈরি করা

প্রথমে টার্মিনালে কমান্ড দিয়ে `App/Http/Controllers/Admin` ফোল্ডারের অধীনে একটি কন্ট্রোলার তৈরি করুন:

```bash
php artisan make:controller Admin/DashboardController

```

---

## ২. রাউট সেটআপ করা (`routes/web.php`)

সরাসরি কলব্যাক ফাংশন তুলে দিয়ে ড্যাশবোর্ড কন্ট্রোলারের `index` মেথডকে রাউটে যুক্ত করুন:

```php
use App\Http\Controllers\Admin\DashboardController;

Route::middleware(['auth'])->prefix('admin')->group(function () {
    // কন্ট্রোলার নির্ভর ড্যাশবোর্ড রাউট
    Route::get('/dashboard', [DashboardController::class, 'index'])->name('admin.dashboard');
});

```

---

## ৩. কন্ট্রোলারে লজিক যুক্ত করা (`DashboardController.php`)

কন্ট্রোলার ফাইলে `Post` মডেল ইম্পোর্ট করে মোট পোস্ট গণনা করুন এবং `compact()` ফাংশনের মাধ্যমে তা ভিউ ফাইলে পাঠান:

```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\Post;
use Illuminate\Http\Request;

class DashboardController extends Controller
{
    public function index()
    {
        // ডাটাবেজ থেকে মোট পোস্টের সংখ্যা গণনা
        $totalPost = Post::count();

        // ভিউ ফাইলে ডাটা পাঠানো
        return view('admin.dashboard', compact('totalPost'));
    }
}

```

---

## ৪. ড্যাশবোর্ডে ডায়নামিক ডাটা প্রদর্শন (`dashboard.blade.php`)

`resources/views/admin/dashboard.blade.php` ফাইলে স্ট্যাটিক বা ডামি সংখ্যার জায়গায় পাস করা ভেরিয়েবলটি বসিয়ে দিন:

```html
<div class="bg-white p-6 rounded-lg shadow">
    <h3 class="text-gray-500 text-sm font-medium">মোট পোস্ট</h3>
    <!-- ডায়নামিক পোস্ট সংখ্যা -->
    <p class="text-3xl font-bold text-gray-800 mt-2">
        {{ $totalPost }}
    </p>
</div>

```

---

## ৫. লজিক্যাল ব্যাখ্যা

* **`Post::count()`:** এটি লারাভেল ইলোকুয়েন্ট (Eloquent ORM)-এর একটি বিল্ট-ইন মেথড, যা ডাটাবেজের `posts` টেবিল থেকে মোট রো (Row) সংখ্যা গুনে আনে।


* **`compact('totalPost')`:** এটি পিএইচপির একটি ফাংশন, যা ভেরিয়েবলের নামকে কী (Key) হিসেবে নিয়ে একটি অ্যারে তৈরি করে ভিউ ফাইলে ডাটা পাস করে।


* **Mustache Syntax (`{{ }}`):** এটি লারাভেল ব্লেড টেমপ্লেটিং ইঞ্জিনের সিনট্যাক্স, যা পাস করা ভেরিয়েবলের মান এইচটিএমএলে নিরাপদভাবে (Cross-Site Scripting বা XSS প্রতিরোধ করে) প্রদর্শন করে।
