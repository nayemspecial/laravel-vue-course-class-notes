**প্লাটফর্ম:** প্রযুক্তিপ্লাস একাডেমী (ProjuktiPlus Academy)

**বিষয়:** ১০.৩ ড্যাশবোর্ডের মোট ভিউ, পেন্ডিং কমেন্ট ও সাবস্ক্রাইবার সংখ্যা ডাইনামিক করা। রাউট সেটআপ করা, কন্ট্রোলারে লজিক যুক্ত করা, ডাটাবেজ থেকে মোট ভিউ এর সংখ্যা গণনা, পেন্ডিং বা এপ্রুভ না হওয়া কমেন্ট গণনা, নিউজলেটার সাবস্ক্রাইবার গণনা, ভিউ ফাইলে ডাটা পাঠানো, ড্যাশবোর্ডে ডায়নামিক ডাটা প্রদর্শন।

**প্রযুক্তি প্লাস একাডেমির** পক্ষ থেকে আপনাদের সবাইকে স্বাগতম জানাচ্ছি। আজকের পর্বে আমরা আমাদের ড্যাশবোর্ডের মোট ভিউ (Total Views), নতুন বা পেন্ডিং কমেন্ট (Pending Comments) এবং সাবস্ক্রাইবার (Subscribers) সংক্রান্ত ডাটাগুলোকে ডাটাবেজ থেকে এনে ডায়নামিক করার কাজ সম্পন্ন করব।

নিচে ধাপভিত্তিক সম্পূর্ণ কোড এবং বিস্তারিত ব্যাখ্যা দেওয়া হলো:

## ১. কন্ট্রোলারে লজিক যুক্ত করা (`DashboardController.php`)

`App/Http/Controllers/Admin/DashboardController.php` ফাইলে সংশ্লিষ্ট মডেলগুলো ইম্পোর্ট করে কাউন্ট করার লজিকগুলো লিখুন:

```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\Comment;
use App\Models\NewsletterSubscriber;
use App\Models\PostView;
use Illuminate\Http\Request;

class DashboardController extends Controller
{
    public function index()
    {
        // ১. মোট পোস্ট ভিউ গণনা
        $totalViews = PostView::count();

        // ২. পেন্ডিং বা এপ্রুভ না হওয়া কমেন্ট গণনা
        $pendingComments = Comment::where('is_approved', false)->count();

        // ৩. সক্রিয় নিউজলেটার সাবস্ক্রাইবার গণনা
        $totalSubscribers = NewsletterSubscriber::where('is_active', true)->count();

        // ডাটা ভিউ ফাইলে পাঠানো
        return view('admin.dashboard', compact('totalViews', 'pendingComments', 'totalSubscribers'));
    }
}

```

## ২. মডেলের টাইমস্ট্যাম্প সেটিংস সংক্রান্ত টিপস

অনেক সময় মডেলের মধ্যে টাইমস্ট্যাম্প কাস্টমাইজেশন বা অফ করার প্রয়োজন হয়। যেমন:

```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class PostView extends Model
{
    // তৈরি হওয়ার এবং আপডেট হওয়ার ডিফল্ট টাইমস্ট্যাম্প নিষ্ক্রিয় করা (প্রয়োজন হলে)
    public $timestamps = false;
}

```

> **নোট:** যদি `timestamps` প্রোপার্টি ব্যবহার করেন, তবে খেয়াল রাখবেন এটি যেন অবশ্যই `public` হিসেবে ডিক্লেয়ার করা থাকে। `protected` ব্যবহার করলে লারাভেল এরর প্রদর্শন করবে।
>

## ৩. ড্যাশবোর্ডে ডায়নামিক ডাটা প্রদর্শন (`dashboard.blade.php`)

`resources/views/admin/dashboard.blade.php` ফাইলে ডামি সংখ্যার পরিবর্তে কন্ট্রোলার থেকে পাস করা ভেরিয়েবলগুলো সেট করুন:

```html
<!-- মোট পোস্ট ভিউ -->
<div class="card">
    <h3>মোট ভিউ</h3>
    <p>{{ $totalViews }}</p>
</div>

<!-- পেন্ডিং কমেন্ট -->
<div class="card">
    <h3>নতুন কমেন্ট</h3>
    <p>{{ $pendingComments }}</p>
</div>

<!-- একটিভ সাবস্ক্রাইবার -->
<div class="card">
    <h3>সাবস্ক্রাইবার</h3>
    <p>{{ $totalSubscribers }}</p>
</div>

```

## ৪. লজিক্যাল ব্যাখ্যা

* **`PostView::count()`:** ডাটাবেজে থাকা পোস্ট ভিউ রেকর্ডগুলোর মোট সংখ্যা গণনা করে।


* **`Comment::where('is_approved', false)->count()`:** শুধুমাত্র যেসকল কমেন্ট এখনো এপ্রুভ করা হয়নি (`is_approved = false`) সেগুলোকে ফিল্টার করে নিয়ে আসে।


* **`NewsletterSubscriber::where('is_active', true)->count()`:** শুধুমাত্র অ্যাক্টিভ গ্রাহক বা সাবস্ক্রাইবারদের সংখ্যা নির্ধারণ করে।
