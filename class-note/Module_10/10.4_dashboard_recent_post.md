**প্লাটফর্ম:** প্রযুক্তিপ্লাস একাডেমী (ProjuktiPlus Academy)

**বিষয়:** ১০.৪ ড্যাশবোর্ড কন্ট্রোলারে কোয়েরি সাজানো, সাম্প্রতিক ৫টি পোস্ট ইগার লোডিং ও ভিউ কাউন্ট সহ রিট্রিভ করা, ব্লেড টেমপ্লেটে ডায়নামিক টেবিল তৈরি, ড্যাশবোর্ডে ডায়নামিক ডাটা প্রদর্শন।

**প্রযুক্তি প্লাস একাডেমির** পক্ষ থেকে আপনাদের সবাইকে স্বাগতম জানাচ্ছি। আজকের পর্বে আমরা আমাদের ড্যাশবোর্ডের সাম্প্রতিক পোস্টের (Recent Posts) টেবিলটি লারাভেলে ইগার লোডিং (Eager Loading) এবং `@forelse` লুপ ব্যবহারের মাধ্যমে ডাটাবেজ থেকে সম্পূর্ণ ডায়নামিক করা শিখব।

নিচে ধাপভিত্তিক সম্পূর্ণ কোড এবং বিস্তারিত ব্যাখ্যা দেওয়া হলো:

## ১. ড্যাশবোর্ড কন্ট্রোলারে কোয়েরি সাজানো (`DashboardController.php`)

`App/Http/Controllers/Admin/DashboardController.php` ফাইলে `recentPosts` ডাটা তোলার জন্য ইগার লোডিং, রিলেশন ভিত্তিক কাউন্ট এবং লেটেস্ট রেকর্ড পাওয়ার কোয়েরি লিখুন:

```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\Post;
use Illuminate\Http\Request;

class DashboardController extends Controller
{
    public function index()
    {
        // সাম্প্রতিক ৫টি পোস্ট ইগার লোডিং ও ভিউ কাউন্ট সহ রিট্রিভ করা
        $recentPosts = Post::with('category')
            ->withCount('views')
            ->latest()
            ->take(5)
            ->get();

        return view('admin.dashboard', compact('recentPosts'));
    }
}

```

## ২. ব্লেড টেমপ্লেটে ডায়নামিক টেবিল তৈরি (`dashboard.blade.php`)

`resources/views/admin/dashboard.blade.php` ফাইলে `@forelse` লুপ ও কন্ডিশনাল স্ট্যাটাস ব্যাজ ব্যবহার করে ডাটা রেন্ডার করুন:

```html
<table class="min-w-full divide-y divide-gray-200">
    <thead>
        <tr>
            <th>ছবি</th>
            <th>টাইটেল</th>
            <th>ক্যাটাগরি</th>
            <th>স্ট্যাটাস</th>
            <th>মোট ভিউ</th>
        </tr>
    </thead>
    <tbody class="bg-white divide-y divide-gray-200">
        @forelse ($recentPosts as $post)
            <tr>
                <!-- ফিচার্ড ইমেজ / ফলব্যাক প্লেসহোল্ডার -->
                <td class="px-6 py-4 whitespace-nowrap">
                    <img src="{{ $post->featured_image ?? 'https://picsum.photos/seed/' . $post->id . '/50/50' }}" alt="Post Image" class="w-10 h-10 rounded-full">
                </td>

                <!-- টাইটেল -->
                <td class="px-6 py-4 whitespace-nowrap">
                    {{ $post->title }}
                </td>

                <!-- ক্যাটাগরি -->
                <td class="px-6 py-4 whitespace-nowrap">
                    {{ $post->category->name ?? '-' }}
                </td>

                <!-- স্ট্যাটাস অনুযায়ী ব্যাজ প্রদর্শন -->
                <td class="px-6 py-4 whitespace-nowrap">
                    @if ($post->status === 'published')
                        <span class="badge-published">প্রকাশিত</span>
                    @elseif ($post->status === 'draft')
                        <span class="badge-draft">ড্রাফট</span>
                    @else
                        <span class="badge-archived">আর্কাইভ</span>
                    @endif
                </td>

                <!-- ভিউ কাউন্ট -->
                <td class="px-6 py-4 whitespace-nowrap">
                    {{ $post->views_count }}
                </td>
            </tr>
        @empty
            <!-- ডাটা না থাকলে খালি অবস্থার মেসেজ -->
            <tr>
                <td colspan="5" class="px-6 py-4 text-center text-gray-500">
                    এখনো কোনো পোস্ট করা হয়নি।
                </td>
            </tr>
        @endforelse
    </tbody>
</table>

```

## ৩. লজিক্যাল ব্যাখ্যা

* **`with('category')` (Eager Loading):** এটি $N+1$ কোয়েরি প্রবলেম সমাধান করে। লুপের ভেতর প্রতি পোস্টের ক্যাটাগরি আনতে বারবার ডাটাবেজে কোয়েরি না চালিয়ে, লারাভেল শুরুতেই ক্যাটাগরি টেবিলের ডাটা একসাথে তুলে আনে।


* **`withCount('views')`:** ডাটাবেজের মূল রেকর্ডের সাথে সরাসরি সম্পর্কযুক্ত `views` রিলেশন কাউন্ট করে `views_count` নামে একটি নতুন অ্যাট্রিবিউট মডেল অবজেক্টে যোগ করে দেয়।


* **`latest()->take(5)->get()`:** ডাটাবেজ থেকে তৈরি করার সময়ানুসারে অবরোহী বা ডিসেন্ডিং অর্ডারে (Descending order) প্রথম ৫টি সাম্প্রতিক রেকর্ড রিটার্ন করে।


* **`@forelse ... @empty ... @endforelse`:** এই ব্লেড ডিরেক্টিভটি অ্যারে বা কালেকশন ফাঁকা হলে আলাদা কোনো `@if` শর্ত না লিখে সরাসরি খালি অবস্থার এইচটিএমএল প্রদর্শন করার সুবিধা দেয়।
