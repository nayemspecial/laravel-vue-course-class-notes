**প্লাটফর্ম:** প্রযুক্তিপ্লাস একাডেমী (ProjuktiPlus Academy)

**বিষয়:** ১১.৭ কন্ট্রোলারে আপডেট ও ডেস্ট্রয় মেথড যুক্ত করা, ভ্যালিডেশন (ইউনিক চেক করার সময় বর্তমান ট্যাগের আইডি বাদ দেওয়া হয়েছে), ট্যাগ ডেস্ট্রয় রাউট যুক্ত করা, ইনডেক্স ও এডিট ব্লেড ফাইলে ডিলিট ফর্ম তৈরি

**প্রযুক্তি প্লাস একাডেমির** পক্ষ থেকে আপনাদের সবাইকে স্বাগতম জানাচ্ছি। আজকের পর্বে আমরা লারাভেলে `TagController`-এর `update()` এবং `destroy()` মেথডের মাধ্যমে ট্যাগের তথ্য আপডেট ও সফলভাবে ডিলিট করার সম্পূর্ণ কার্যপ্রণালী শিখব।

নিচে ধাপভিত্তিক কোড এবং লজিক্যাল ব্যাখ্যা দেওয়া হলো:

---

## ১. কন্ট্রোলারে আপডেট ও ডেস্ট্রয় মেথড যুক্ত করা (`TagController.php`)

`app/Http/Controllers/TagController.php` ফাইলে `update` এবং `destroy` মেথড যোগ করুন:

```php
namespace App\Http\Controllers;

use App\Models\Tag;
use Illuminate\Http\Request;

class TagController extends Controller
{
    // ১. ট্যাগ আপডেট মেথড
    public function update(Request $request, Tag $tag)
    {
        // ভ্যালিডেশন (ইউনিক চেক করার সময় বর্তমান ট্যাগের আইডি বাদ দেওয়া হয়েছে)
        $request->validate([
            'name' => 'required|string|max:255|unique:tags,name,' . $tag->id,
        ]);

        // ট্যাগ আপডেট
        $tag->update([
            'name' => $request->name,
        ]);

        return redirect()->route('admin.tags.index')->with('success', 'ট্যাগ সফলভাবে আপডেট হয়েছে।');
    }

    // ২. ট্যাগ ডিলিট মেথড
    public function destroy(Tag $tag)
    {
        $tag->delete();

        return redirect()->route('admin.tags.index')->with('success', 'ট্যাগ ডিলিট করা হয়েছে।');
    }
}

```

## ২. ওয়েব রাউট কনফিগারেশন (`web.php`)

`routes/web.php` ফাইলে ডিলিট মেথডের জন্য `DELETE` রাউটটি যোগ করুন:

```php
use App\Http\Controllers\TagController;
use Illuminate\Support\Facades\Route;

// ট্যাগ ডেস্ট্রয় রাউট
Route::delete('/admin/tags/{tag}', [TagController::class, 'destroy'])->name('admin.tags.destroy');

```

## ৩. ব্লেড ফাইলে ডিলিট ফর্ম তৈরি (`edit.blade.php` ও `index.blade.php`)

লারাভেলে ফর্ম ডিলিট করার জন্য `POST` মেথডের মধ্যে `@method('DELETE')` এবং `@csrf` ডিরেক্টিভ ব্যবহার করতে হয়:

```html
<form action="{{ route('admin.tags.destroy', $tag->id) }}" method="POST" style="display:inline;">
    @csrf

    <button type="submit" class="btn btn-danger">
        <!-- ডিলিট আইকন -->

        </svg>
    </button>

```

## ৪. লজিক্যাল ব্যাখ্যা

* **Unique Validation with Exception (`unique:tags,name,' . $tag->id`):** ট্যাগ আপডেট করার সময় যদি নাম পরিবর্তন না করে সেভ দেওয়া হয়, তবে লারাভেল যেন তা অলরেডি টেকেন (Already Taken) না ধরে। এটি বর্তমান ট্যাগের আইডিটি বাদে ডাটাবেজের বাকি রেকর্ডের সাথে নাম মিলিয়ে দেখে।


* **`@method('DELETE')` & `@csrf`:** ব্রাউজার সরাসরি HTTP `DELETE` রিকোয়েস্ট সাপোর্ট করে না, তাই ফর্মে `POST` মেথড দিয়ে লারাভেলের মেথড স্পুফিং (`@method('DELETE')`) এবং সিকিউরিটির জন্য CSRF টোকেন ব্যবহার করতে হয়।


* **`button type="submit"`:** ফর্মে বাটন টাইপ `button`-এর পরিবর্তে `submit` রাখা বাধ্যতামূলক, তা না হলে ক্লিক করলে ফর্মটি সাবমিট হবে না।
