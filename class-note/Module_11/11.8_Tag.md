এই পর্বে আমরা আমাদের ইন্ডেক্স পেইজে যে শো বাটন আছে, এই টাইপের শো বাটন নিয়ে কাজ করব। তো চলুন আমরা কোড এডিটর-এ চলে যাই। কোড এডিটর-এ গিয়ে আমরা দেখব যে আমাদের রাউট আছে কিনা। আমাদের একটা রাউট তৈরি করতে হবে। এটার জন্য ডুপ্লিকেট করছি। ডুপ্লিকেট করে এটা অবশ্যই আমাদের গেট (GET) রাউট হবে। তো গেট রাউট নিলাম।

এরপর দেখা যাচ্ছে যে এই জায়গায় আমাদের `admin/tags` এটা ঠিক আছে। `TagController` ক্লাস, এই জায়গায় এসে আমাদের মেথডটা চেঞ্জ করতে হবে। `show` মেথড, আর এখানে এসে আমাদের যে লাস্টে ফাইলটা আছে সেই ফাইলটা চেঞ্জ করতে হবে। তো এই ফাইলটাকে আমি বলছি `show` নেম রাউটের ভেতরে।

তো আমাদের যখন এটা তৈরি করা হয়ে যাচ্ছে, আমাদের কন্ট্রোলার ফাইল আছে। এই মেথডটা আমাদের দরকার। তো আমরা চলে যাচ্ছি আমাদের `TagController`-এ। `TagController`-এ আমাদের `show` মেথডটা দরকার। সাধারণত দেখা যাচ্ছে যে নিচেই করা যায়, তো আমরা মেথডগুলো পরবর্তীতে সাজাব, এখন এখানে করছি:

```php
public function show()
{
    // ...
}

```

এর মধ্যে এসে আমরা আমাদের যে ভিউ আছে, সেই ভিউটা এখান থেকে ধরায় দিতে পারি বা আরও যে বিষয়গুলো আছে সেগুলো আমরা এখান থেকে কন্ট্রোল করতে পারি। তো কি কি এখানে দেখা যাচ্ছে—ট্যাগ, তারপর পোস্ট—এই টাইপের বিষয়গুলো এখানে আমরা সুন্দর করে নিয়ে আসতে পারি। তো আমি যে কাজটা করছি:

```php
return view('admin.tags.show');

```

তাহলে এটাকে আমাদের ট্যাগের ভেতরে তৈরি করতে হবে। তো আমি একটা ফাইল ক্রিয়েট করে ফেলি—`show.blade.php`। এভাবে আমরা একটা ফাইল ক্রিয়েট করলাম।

এটার আবার কোড আছে আমাদের এই ট্যাগ কার্ডের ভেতরে `show.html`-এ। তো এখানে এসে আমরা আবার ফাইন্ড করতে পারি `main` tag। তো এখান থেকে আমি মেইন অংশটুকু কপি করলাম। কপি করে আমাদের যে `show.blade.php` আছে, এখানে এসে আমরা এটাকে দিয়ে দিব।

তো এক্সটেন্ড করলাম:

```php
@extends('admin.layouts.app')

@section('content')
    {{-- মেইন কন্টেন্ট --}}
@endsection

```

তবে মেইন ট্যাগটা আমাদের এখানে ইউজ করা যাবে না, মেইন রয়েছে আমাদের মাস্টার লেআউটে। ওকে, তো এভাবে দিলাম। দেওয়ার পর আমরা যদি এখন এখানে আসি, আসার পর কোন একটাকে যদি এভাবে ক্লিক করি... একটু রিলোড দিতে হবে। আচ্ছা, আমরা যাব `tags`-এ।

এখানে যে ইন্ডেক্সের বাটনটা, এই বাটনে আমাদের আবার একটু ডাইনামিক করতে হবে। তো আমরা ওইখানে যাই। আমাদের যে ইন্ডেক্স ফাইলটা আছে সেটা অন হয়ে আছে। ইন্ডেক্সের একেবারে লাস্টে যেখানে যেখানে আমাদের এটা দরকার, সেখানে আসছি। তো বিস্তারিত মানে হচ্ছে এইটা। এই জায়গায় যে রাউটটা আছে, সেই রাউটটা আমাদের ঠিক করে দিতে হবে। তো আমরা রাউটটা এখানে দিয়ে দিচ্ছি:

```html
route('admin.tags.show')

```

ওকে, তো এখন যদি আমি এখানে ক্লিক করি, এইবার দেখুন এটা আসছে। এই যে আমাদের যে টেমপ্লেটটা, সেই টেমপ্লেটটা কিন্তু এখন এখানে সুন্দর করে চলে আসলো।

আচ্ছা, এবার আমাদের এই টাইপের যে বিষয়গুলো আছে, সেগুলোকে ডাইনামিক করতে হবে। যাতে করে মোট পোস্ট সংখ্যা আসে, প্রকাশিত (পাবলিশড) পোস্ট, ড্রাফট পোস্ট—এইগুলো এখানে আনতে হবে। তারপর এখানে দেখা যাচ্ছে এডিট ট্যাগ, 'এই ট্যাগ যুক্ত পোস্ট সমূহ'—এই ব্যাপারগুলোকে ডাইনামিক করার চেষ্টা করতে হবে। সে ক্ষেত্রে আমাদের বেশ কিছু ডাটা লাগবে। তো দেখি আমরা কি কি ডাটা নিয়ে কাজ করতে পারি।

প্রথমেই আমরা দেখতে পাচ্ছি, আমরা এখানে বললাম:

```html
route('admin.tags.index')

```

তো এটাকে এখান থেকে ঠিক করে দিলাম। এবার এখানে একটা `<h1>` দেখা যাচ্ছে, এটাকে ডাইনামিক করে দিই। কিভাবে করব? এখানে ট্যাগের নেম আসবে। তাই বললাম:

```html
{{ $tag->name }}

```

এখন এই `$tag` কি আমাদের কন্ট্রোলারের মেথডের মধ্যে আছে? যদি না থাকে, তবে নিয়ে আসতে হবে যাতে ট্যাগটা এখানে সংজ্ঞায়িত হয়। সে ক্ষেত্রে আমরা চলে যাচ্ছি আমাদের মেথডে। ডাটা মডেল বাইন্ডিং-এর মাধ্যমে নিয়ে আসতে পারি:

```php
public function show(Tag $tag)
{
    return view('admin.tags.show', compact('tag'));
}

```

এবার কিন্তু ডাটা চলে আসবে। দেখুন, এটা কিন্তু এখন ডাটাবেস থেকে আসছে।

এরপর স্লাগ (slug)। স্লাগের ভ্যালু কোডের ভেতরে রয়েছে:

```html
{{ $tag->slug }}

```

আর এই ডেটটার জন্য আমাদের কিছু কাজ করতে হবে, এটা তো ডাইনামিক হতে হবে:

```html
{{ $tag->created_at->translatedFormat('d F, Y') }}

```

তাহলে এভাবে একটা ডেট চলে আসছে এখানে।

এরপর নিচে গিয়ে এডিট বাটন রয়েছে। এই বাটনগুলোকে ডাইনামিক করে দিতে হবে:

```html
href="{{ route('admin.tags.edit', $tag->id) }}"

```

এবং 'সব ট্যাগ' বাটন:

```html
href="{{ route('admin.tags.index') }}"

```

এই দুইটা বাটনকে ডাইনামিক করে ফেললাম।

এরপর আমাদের স্টেটগুলো রয়েছে—মোট পোস্ট। এটাকে ডাইনামিক করার জন্য আমরা শো মেথডে ভেরিয়েবলগুলো ডিফাইন করে ফেলব:

```php
$totalPost = $tag->posts()->count();

```

এই `$totalPost`-কে কমপ্যাক্ট-এর মধ্যে রেখে দিব।

এরপর প্রকাশিত (পাবলিশড) পোস্ট:

```php
$publishedPost = $tag->posts()->where('status', 'published')->count();

```

এরপর ড্রাফট পোস্ট:

```php
$draftPost = $tag->posts()->where('status', 'draft')->count();

```

আর রিলেটেড পোস্টের জন্য:

```php
$relatedPost = $tag->posts()->take(10)->get();

```

কমপ্যাক্ট করে সব পাঠাব:

```php
return view('admin.tags.show', compact('tag', 'totalPost', 'publishedPost', 'draftPost', 'relatedPost'));

```

ভিউ ফাইলে এসে ডাটাগুলো বসাব:

* মোট পোস্ট: `{{ $totalPost }}`
* প্রকাশিত পোস্ট: `{{ $publishedPost }}`
* ড্রাফট পোস্ট: `{{ $draftPost }}`

এবার রিলেটেড পোস্ট টেবিল বডিতে লুপ শুরু করব:

```blade
@forelse($relatedPost as $post)
    <tr>
        <td>
            @if($post->featured_image)
                <img src="{{ $post->featured_image }}" alt="{{ $post->title }}">
            @else
                {{-- Fallback Image --}}
            @endif
        </td>
        <td>{{ $post->title }}</td>
        <td>
            @if($post->status == 'published')
                <span>প্রকাশিত</span>
            @elseif($post->status == 'draft')
                <span>ড্রাফট</span>
            @else
                <span>আর্কাইভ</span>
            @endif
        </td>
        <td>
            {{ $post->published_at ? $post->published_at->translatedFormat('d F, Y') : $post->created_at->translatedFormat('d F, Y') }}
        </td>
    </tr>
@empty
    <tr>
        <td colspan="4">কোন পোস্ট যুক্ত করা হয়নি।</td>
    </tr>
@endforelse

```

আমরা যা যা করেছি তা হচ্ছে—ওয়েব রাউটে ৭টি নতুন রাউট (`index`, `create`, `store`, `show`, `edit`, `update`, `destroy`) লিখে ফেলছি। কন্ট্রোলার তৈরি করে তার ভেতরে সকল মেথডগুলো লিখেছি। স্ট্যাটিক পেজগুলো থেকে কন্টেন্ট নিয়ে `tags` ফোল্ডারে `index.blade.php`, `create.blade.php`, `edit.blade.php`, `show.blade.php` আকারে রাখছি। সর্বশেষ সাইডবার পার্সিয়ালে লিংকগুলো আপডেট করেছি।

ট্যাগ তালিকায় ফিরে যেতে পারছি, এডিটে গিয়ে এডিট করতে পারছি, ডিলিট করতে পারছি—এটাকেই বলা হয় ক্রাড (CRUD - Create, Read, Update, Delete) অপারেশন।

আমরা এই পর্ব এখানে শেষ করছি। আগামী পর্বে আবার দেখা হচ্ছে।
