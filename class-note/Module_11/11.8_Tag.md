**প্লাটফর্ম:** প্রযুক্তিপ্লাস একাডেমী (ProjuktiPlus Academy)

**বিষয়:** ১১.৮ ট্যাগ ডিটেইলস বা শো পেজের জন্য একটি রাউট তৈরি করা, কন্ট্রোলারে শো মেথড লজিক (টোটাল পোস্ট সংখ্যা, পাবলিশড পোস্ট সংখ্য্‌ ড্রাফট পোস্ট সংখ্যা, রিলেটেড পোস্ট কুয়েরি করা) লেখা, ভিউ ফাইল তৈরি ও ডাইনামিক করা।

**প্রযুক্তি প্লাস একাডেমির** পক্ষ থেকে আপনাদের সবাইকে স্বাগতম জানাচ্ছি। এই পর্বে আমরা আমাদের লারাভেল প্রজেক্টের ইন্ডেক্স পেইজে যে "শো" (Show) বাটন রয়েছে, সেটির ব্যাকএন্ড লজিক ও ভিউ ফাইল ডাইনামিক করার কাজ করবো।

নিচে আজকের টিউটোরিয়ালের সম্পূর্ণ কোড এবং ধাপগুলো সাজিয়ে দেওয়া হলো:

---

### ১. রাউট তৈরি করা (`routes/web.php`)

প্রথমে আমাদের ট্যাগ ডিটেইলস বা শো পেজের জন্য একটি `GET` রাউট ডিফাইন করতে হবে:

```php
Route::get('admin/tags/{tag}', [TagController::class, 'show'])->name('admin.tags.show');

```

---

### ২. কন্ট্রোলার মেথড তৈরি (`TagController.php`)

মডেল বাইন্ডিং ব্যবহার করে ট্যাগের তথ্য এবং ওই ট্যাগের সাথে যুক্ত পোস্টের বিভিন্ন পরিসংখ্যান (Stat) বের করে ভিউতে পাঠাবো:

```php
use App\Models\Tag;

public function show(Tag $tag)
{
    // মোট পোস্ট সংখ্যা
    $totalPost = $tag->posts()->count();

    // প্রকাশিত পোস্ট সংখ্যা
    $publishedPost = $tag->posts()->where('status', 'published')->count();

    // ড্রাফট পোস্ট সংখ্যা
    $draftPost = $tag->posts()->where('status', 'draft')->count();

    // সম্পর্কিত ১০টি পোস্ট
    $relatedPost = $tag->posts()->take(10)->get();

    return view('admin.tags.show', compact('tag', 'totalPost', 'publishedPost', 'draftPost', 'relatedPost'));
}

```

---

### ৩. ইন্ডেক্স ফাইলে রাউট লিংক ডাইনামিক করা (`index.blade.php`)

ট্যাগ টেবিলের "বিস্তারিত" বা "শো" বাটনে রাউটটি যুক্ত করুন:

```html
<a href="{{ route('admin.tags.show', $tag->id) }}" class="btn btn-info btn-sm">
    বিস্তারিত
</a>

```

---

### ৪. ভিউ ফাইল তৈরি ও ডাইনামিক করা (`resources/views/admin/tags/show.blade.php`)

লেআউট এক্সটেন্ড করে ট্যাগের নাম, স্লাগ, তৈরির তারিখ এবং পরিসংখ্যানগুলো বসিয়ে দিন:

```blade
@extends('admin.layouts.app')

@section('content')
<div class="container-fluid">
    {{-- ট্যাগ হেডার ও বেসিক ইনফো --}}
    <div class="d-flex justify-content-between align-items-center mb-4">
        <h2>{{ $tag->name }}</h2>
        <div>
            <a href="{{ route('admin.tags.edit', $tag->id) }}" class="btn btn-warning">এডিট ট্যাগ</a>
            <a href="{{ route('admin.tags.index') }}" class="btn btn-secondary">সব ট্যাগ</a>
        </div>
    </div>

    <p><strong>স্লাগ:</strong> {{ $tag->slug }}</p>
    <p><strong>তৈরি হয়েছে:</strong> {{ $tag->created_at->translatedFormat('d F, Y') }}</p>

    {{-- কাউন্টার কার্ডসমূহ --}}
    <div class="row my-4">
        <div class="col-md-4">
            <div class="card bg-primary text-white p-3">
                <h5>মোট পোস্ট</h5>
                <h3>{{ $totalPost }}</h3>
            </div>
        </div>
        <div class="col-md-4">
            <div class="card bg-success text-white p-3">
                <h5>প্রকাশিত পোস্ট</h5>
                <h3>{{ $publishedPost }}</h3>
            </div>
        </div>
        <div class="col-md-4">
            <div class="card bg-secondary text-white p-3">
                <h5>ড্রাফট পোস্ট</h5>
                <h3>{{ $draftPost }}</h3>
            </div>
        </div>
    </div>

    {{-- সম্পর্কিত পোস্টের তালিকা --}}
    <h4>এই ট্যাগ যুক্ত পোস্ট সমূহ</h4>
    <table class="table table-bordered mt-3">
        <thead>
            <tr>
                <th>ছবি</th>
                <th>শিরোনাম</th>
                <th>স্ট্যাটাস</th>
                <th>তারিখ</th>
            </tr>
        </thead>
        <tbody>
            @forelse($relatedPost as $post)
                <tr>
                    <td>
                        @if($post->featured_image)
                            <img src="{{ $post->featured_image }}" alt="{{ $post->title }}" width="50">
                        @else
                            <img src="{{ asset('images/default.png') }}" alt="Default" width="50">
                        @endif
                    </td>
                    <td>{{ $post->title }}</td>
                    <td>
                        @if($post->status == 'published')
                            <span class="badge bg-success">প্রকাশিত</span>
                        @elseif($post->status == 'draft')
                            <span class="badge bg-warning">ড্রাফট</span>
                        @else
                            <span class="badge bg-dark">আর্কাইভ</span>
                        @endif
                    </td>
                    <td>
                        {{ $post->published_at ? $post->published_at->translatedFormat('d F, Y') : $post->created_at->translatedFormat('d F, Y') }}
                    </td>
                </tr>
            @empty

                    <td colspan="4" class="text-center">কোন পোস্ট যুক্ত করা হয়নি।</td>
                </tr>
            @endforelse
        </tbody>
    </table>
</div>
@endsection

```

---

এর মাধ্যমে আমাদের ট্যাগের সম্পূর্ণ **CRUD (Create, Read, Update, Delete)** অপারেশন সফলভাবে সম্পন্ন হলো। পরবর্তী পর্বে আমরা নতুন আরেকটি বিষয় নিয়ে আলোচনা করবো।
