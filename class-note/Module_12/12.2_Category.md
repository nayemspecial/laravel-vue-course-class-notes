আজকের ক্লাসে সবাইকে স্বাগতম। গত ক্লাসে আমরা রিসোর্স রাউট এবং রিসোর্স কন্ট্রোলার সেটআপ করেছিলাম। আজকের পর্বে আমরা ক্যাটাগরির লিস্ট দেখানোর জন্য **ইন্ডেক্স পেজ (`index.blade.php`)** তৈরি করব এবং ডাটাবেজ থেকে ডাটা এনে ডাইনামিক করব।

কাজে নামার আগে আজকের ক্লাসের ওয়ার্কফ্লো অনুযায়ী ফাইল এবং মেথডগুলো দেখে নেওয়া যাক:

* **`resources/views/admin/categories/index.blade.php`:** ক্যাটাগরি লিস্ট ও টেবিল ডাইনামিক করার জন্য।


* **`app/Http/Controllers/Admin/CategoryController.php`:** `index()` মেথডে ডাটাবেজ থেকে ক্যাটাগরি ফেচ করে ভিউতে পাঠানোর জন্য।

### ১. ব্লেড ফাইল তৈরি ও লেআউট এক্সটেন্ড (`index.blade.php`)

প্রথমে `resources/views/admin` ফোল্ডারের ভেতর `categories` নামের একটি ফোল্ডার তৈরি করব এবং তার ভেতর `index.blade.php` ফাইলটি নেব। এরপর স্ট্যাটিক ফাইল থেকে টেমপ্লেটের মূল কন্টেন্ট অংশটুকু নিয়ে লেআউট এক্সটেন্ড করে নেব:

```html
@extends('admin.layouts.app')

@section('content')
    <!-- সাকসেস মেসেজ শো করার জন্য -->
    @if (session('success'))
        <div class="alert alert-success">
            {{ session('success') }}
        </div>
    @endif

    <div class="container-fluid">
        <!-- নতুন ক্যাটাগরি তৈরির বাটন -->
        <a href="{{ route('admin.categories.create') }}" class="btn btn-primary mb-3">নতুন ক্যাটাগরি</a>

        <!-- মোট ক্যাটাগরি সংখ্যা -->
        <h5>মোট ক্যাটাগরি: {{ $categories->count() }} টি</h5>

        <table class="table table-bordered">
            <thead>
                <tr>
                    <th>সিরিয়াল</th>
                    <th>নাম</th>
                    <th>স্লাগ</th>
                    <th>পোস্ট সংখ্যা</th>
                    <th>স্ট্যাটাস</th>
                    <th>অ্যাকশন</th>
                </tr>
            </thead>
            <tbody>
                @forelse ($categories as $category)
                    <tr>
                        <td>{{ $category->sort_order }}</td>
                        <td>
                            <i class="{{ $category->icon ?? 'fa fa-folder' }}" style="color: {{ $category->color ?? '#000' }}"></i>
                            {{ $category->name }}
                        </td>
                        <td>{{ $category->slug }}</td>
                        <td>{{ $category->posts_count }}</td>
                        <td>
                            @if ($category->is_active)
                                <span class="badge bg-success">সক্রিয়</span>
                            @else
                                <span class="badge bg-danger">নিষ্ক্রিয়</span>
                            @endif
                        </td>
                        <td>
                            <!-- বিস্তারিত (Show) -->
                            <a href="{{ route('admin.categories.show', $category) }}" class="btn btn-sm btn-info">বিস্তারিত</a>

                            <!-- এডিট (Edit) -->
                            <a href="{{ route('admin.categories.edit', $category) }}" class="btn btn-sm btn-warning">এডিট</a>

                            <!-- ডিলিট (Delete Form) -->
                            <form action="{{ route('admin.categories.destroy', $category) }}" method="POST" class="d-inline">
                                @csrf
                                @method('DELETE')
                                <button type="submit" class="btn btn-sm btn-danger" onclick="return confirm('আপনি কি নিশ্চিত?')">ডিলিট</button>

                        </td>
                    </tr>

                    <tr>
                        <td colspan="6" class="text-center">এখনো কোনো ক্যাটাগরি ক্রিয়েট করা হয়নি।</td>
                    </tr>
                @endforelse
            </tbody>
        </table>
    </div>
@endsection
```

### ২. কন্ট্রোলারে ডাটা ফেচ করা (`CategoryController.php`)

এখন ডাটাবেজ থেকে ক্যাটাগরিগুলো নিয়ে এসে এবং এর সাথে কতগুলো পোস্ট যুক্ত আছে তা গণনা করতে `withCount('posts')` ব্যবহার করে ভিউ ফাইলে পাঠাব:

```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\Category;
use Illuminate\Http\Request;

class CategoryController extends Controller
{
    /**
     * ক্যাটাগরি ইন্ডেক্স পেজ ও ডাটা প্রদর্শন
     */
    public function index()
    {
        // পোস্টের সংখ্যা গণনা করে ক্যাটাগরি ফেচ করা
        $categories = Category::withCount('posts')->get();

        // ভিউতে ডাটা কমপ্যাক্ট করে পাস করা
        return view('admin.categories.index', compact('categories'));
    }
}

```

আজকের ক্লাসে আমরা সফলতা সহকারে ক্যাটাগরি ইন্ডেক্স পেজের টেবিলটি ডাটাবেজের সাথে ডাইনামিক করলাম, কাস্টম সিএসএস স্ট্যাটাস ব্যাজ বসালাম এবং শাউট/এডিট/ডিলিট রাউটগুলো সেটআপ করলাম।

পরবর্তী পর্বে আমরা **নতুন ক্যাটাগরি তৈরি করার ফর্ম (`create.blade.php`)** এবং ডাটা সেভ করার লজিক নিয়ে কাজ করব।
