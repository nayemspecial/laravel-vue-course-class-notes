**প্লাটফর্ম:** প্রযুক্তিপ্লাস একাডেমী (ProjuktiPlus Academy)

**বিষয়:** ১২.৩ সাইডবারে ক্যাটাগরি মেনু ও অ্যাক্টিভ স্টেট যোগ করা, ন্ট্রোলারে ভিউ রিটার্ন করা, নতুন ক্যাটাগরি তৈরির ফর্ম প্রদর্শন করা, ক্যাটাগরি ক্রিয়েট ব্লেড ফাইল তৈরি ও ডাইনামিক করা ।

**প্রযুক্তি প্লাস একাডেমির** পক্ষ থেকে আপনাদের সবাইকে স্বাগতম জানাচ্ছি। গত ক্লাসে আমরা রিসোর্স রাউটের মাধ্যমে ক্যাটাগরি ইন্ডেক্স পেজ এবং তালিকা প্রদর্শন করার কাজ শেষ করেছিলাম। আজকের পর্বে আমরা **নতুন ক্যাটাগরি তৈরি করার ফর্ম (`create.blade.php`)** তৈরি করব, সাইডবারের অ্যাক্টিভ মেনু ফিক্স করব এবং ফর্মের ইনপুট ফিল্ডগুলো ডাইনামিক করব।

আজকের ক্লাসের মূল ধাপ ও ফাইলসমূহ:

* **সাইডবার অ্যাক্টিভ মেনু সেটআপ:** `resources/views/admin/layouts/partials/sidebar.blade.php`
* **কন্ট্রোলার মেথড আপডেট:** `app/Http/Controllers/Admin/CategoryController.php`-এর `create()` মেথডে ভিউ রিটার্ন করা।
* **ক্রিয়েট ব্লেড ভিউ ফাইল:** `resources/views/admin/categories/create.blade.php` তৈরি ও ডাইনামিক করা।

### ১. সাইডবারে ক্যাটাগরি মেনু ও অ্যাক্টিভ স্টেট সেটআপ

প্রথমে `sidebar.blade.php` ফাইলে গিয়ে ক্যাটাগরি মেনুটিকে সিলেক্টেড করার জন্য উপযুক্ত আইকন ও ক্যাটাগরি রাউট সেট করব:

```html
<li class="nav-item {{ request()->routeIs('admin.categories.*') ? 'active' : '' }}">
    <a class="nav-link" href="{{ route('admin.categories.index') }}">
        <i class="fa fa-folder"></i>
        <span>ক্যাটাগরি</span>
    </a>
</li>

```

### ২. কন্ট্রোলারে ভিউ রিটার্ন করা (`CategoryController.php`)

ক্যাটাগরি কন্ট্রোলারের `create()` মেথডে গিয়ে নতুন ক্যাটাগরি তৈরির ব্লেড ফাইলটি রিটার্ন করব:

```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;

class CategoryController extends Controller
{
    /**
     * নতুন ক্যাটাগরি তৈরির ফর্ম প্রদর্শন
     */
    public function create()
    {
        return view('admin.categories.create');
    }
}

```

### ৩. ক্যাটাগরি ক্রিয়েট ব্লেড ফাইল তৈরি ও ডাইনামিক করা (`create.blade.php`)

`resources/views/admin/categories/` ফোল্ডারের ভেতর `create.blade.php` ফাইল নিয়ে লেআউট এক্সটেন্ড করব এবং ফর্মের ফিল্ডগুলোতে `CSRF` টোকেন, validation error এবং `old()` হেলপার মেথড যুক্ত করব:

```html
@extends('admin.layouts.app')

@section('content')
<div class="container-fluid">
    <div class="d-flex justify-content-between align-items-center mb-3">
        <h4>নতুন ক্যাটাগরি তৈরি করুন</h4>
        <a href="{{ route('admin.categories.index') }}" class="btn btn-secondary">তালিকায় ফিরে যান</a>
    </div>

    <form action="{{ route('admin.categories.store') }}" method="POST">
        @csrf

        <!-- ক্যাটাগরির নাম -->
        <div class="form-group mb-3">
            <label for="name">ক্যাটাগরির নাম</label>
            <input type="text" name="name" id="name" class="form-control @error('name') is-invalid @enderror" value="{{ old('name') }}">
            @error('name')
                <span class="text-danger small">{{ $message }}</span>
            @enderror
        </div>

        <!-- বিবরণ -->
        <div class="form-group mb-3">
            <label for="description">বিবরণ</label>
            <textarea name="description" id="description" class="form-control @error('description') is-invalid @enderror">{{ old('description') }}</textarea>
            @error('description')
                <span class="text-danger small">{{ $message }}</span>
            @enderror
        </div>

        <!-- আইকন -->
        <div class="form-group mb-3">
            <label for="icon">আইকন (FontAwesome class)</label>
            <input type="text" name="icon" id="icon" class="form-control" value="{{ old('icon', 'fa fa-folder') }}">
        </div>

        <!-- কালার -->
        <div class="form-group mb-3">
            <label for="color">কালার কোড</label>
            <input type="color" name="color" id="color" class="form-control form-control-color" value="{{ old('color', '#000000') }}">
        </div>

        <!-- সিরিয়াল / সর্ট অর্ডার -->
        <div class="form-group mb-3">
            <label for="sort_order">সিরিয়াল নাম্বার</label>
            <input type="number" name="sort_order" id="sort_order" class="form-control" value="{{ old('sort_order', 0) }}">
        </div>

        <!-- স্ট্যাটাস -->
        <div class="form-check form-switch mb-3">
            <input type="checkbox" name="is_active" id="is_active" class="form-check-input" value="1" checked>
            <label class="form-check-label" for="is_active">সক্রিয়</label>
        </div>

        <!-- সাবমিট ও ক্যানসেল বাটন -->
        <button type="submit" class="btn btn-success">সংরক্ষণ করুন</button>
        <a href="{{ route('admin.categories.index') }}" class="btn btn-light">বাতিল</a>
    </form>
</div>
@endsection

```

---

আজকের ক্লাসে আমরা সাকসেসফুলি ক্রিয়েট ফর্মিট লেআউট এক্সটেন্ড করে ডাইনামিক করলাম এবং ইনপুট ভ্যালিডেশন ফেল করলেও ডাটা যেন মুছে না যায় সেজন্য `old()` হেলপার মেথড কনফিগার করলাম।

পরবর্তী পর্বে আমরা **CategoryController-এর `store()` মেথডে ভ্যালিডেশন লজিক এবং ডাটাবেজে ডাটা সেভ করার প্রসেস** নিয়ে কাজ করব।
