আজকের ক্লাসে সবাইকে স্বাগতম। গত পর্বে আমরা নতুন ক্যাটাগরি তৈরি করার জন্য `create.blade.php` ফর্ম শো করানোর কাজটি সম্পন্ন করেছিলাম। আজকের পর্বে আমরা ফর্মে ইনপুট দেওয়া ডাটা ভ্যালিডেশন করে ডাটাবেজে সেভ করার সম্পূর্ণ প্রসেসটি শিখব।

আজকের ক্লাসের মূল ধাপ ও ফাইলসমূহ:

* **কন্ট্রোলার রিকোয়েস্ট চেকিং:** `app/Http/Controllers/Admin/CategoryController.php`-এ `dd($request->all())` দিয়ে ইনপুট টেস্ট।


* **ইনপুট ভ্যালিডেশন (Validation):** নেম, ডেসক্রিপশন, আইকন, কালার ও সর্ট অর্ডারের রুলস সেট করা।


* **ডাটা ইনসার্ট ও স্লাগ জেনারেশন:** `Category::create()` মডেলে ডাটা পাস করা এবং `Illuminate\Support\Str::slug()` ব্যবহার করে স্লাগ তৈরি করা।


* **রিডাইরেক্ট ও সাকসেস মেসেজ:** ইন্ডেক্স পেজে রিডাইরেক্ট করে নোটিফিকেশন মেসেজ দেখানো।

### ২. ক্যাটাগরি কন্ট্রোলারে ডাটা সেভ করার লজিক (`CategoryController.php`)

ক্যাটাগরি ডাটা ভ্যালিডেট করে ডাটাবেজে সেভ করার জন্য `store()` মেথডটি নিম্নোক্তভাবে আপডেট করব:

```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\Category;
use Illuminate\Http\Request;
use Illuminate\Support\Str;

class CategoryController extends Controller
{
    /**
     * নতুন ক্যাটাগরি ডাটাবেজে সংরক্ষণ করা
     */
    public function store(Request $request)
    {
        // ১. ইনপুট ডাটা ভ্যালিডেশন
        $validated = $request->validate([
            'name'        => 'required|string|max:100|unique:categories,name',
            'description' => 'nullable|string',
            'icon'        => 'nullable|string|max:50',
            'color'       => 'nullable|string|max:20',
            'sort_order'  => 'nullable|integer|min:0',
        ]);

        // ২. ডাটাবেজে ক্যাটাগরি ক্রিয়েট করা
        Category::create([
            'name'        => $validated['name'],
            'slug'        => Str::slug($validated['name']), // নাম থেকে অটো স্লাগ তৈরি
            'description' => $validated['description'] ?? null,
            'icon'        => $validated['icon'] ?? null,
            'color'       => $validated['color'] ?? null,
            'sort_order'  => $validated['sort_order'] ?? 0,
            'is_active'   => $request->boolean('is_active'), // বুলিয়ান ভ্যালু চেক
        ]);

        // ৩. ক্যাটাগরি লিস্ট পেজে রিডাইরেক্ট ও সাকসেস মেসেজ
        return redirect()
            ->route('admin.categories.index')
            ->with('success', 'ক্যাটাগরি সফলভাবে তৈরি হয়েছে।');
    }
}

```

---

### ৩. কাজের মূল বিষয়গুলো

* **`Str::slug()`:** ক্যাটাগরির নাম (যেমন: `PHP Laravel`) থেকে অটোমেটিক স্লাগ (যেমন: `php-laravel`) তৈরি করতে লারাভেলের `Illuminate\Support\Str` হেলপার ব্যবহার করা হয়েছে।


* **`$request->boolean('is_active')`:** চেকবক্স সিলেক্ট থাকলে `true` এবং না থাকলে `false` সেট করবে।


* **`with('success', ...)`:** ডাটা সেভ হওয়ার পর ইন্ডেক্স পেজে সাকসেস মেসেজ পাঠাবে, যা আমরা আগের ক্লাসে ইন্ডেক্স ভিউতে সেট করেছিলাম।
