প্রিয় শিক্ষার্থীবৃন্দ,

আজকের ক্লাসে সবাইকে স্বাগতম। গত পর্বে আমরা নতুন ক্যাটাগরি তৈরি করার জন্য ডাটা ভ্যালিডেশন এবং ডাটাবেজে সেভ করার কাজ সম্পন্ন করেছিলাম। আজকের পর্বে আমরা ক্যাটাগরি এডিট অপশন নিয়ে কাজ করব এবং এডিট ফর্মটি সম্পূর্ণ ডাইনামিক করে ভিউতে শো করাব।

আজকের ক্লাসের মূল ধাপ ও ফাইলসমূহ:

* **কন্ট্রোলারে এডিট ভিউ ও ডাটা পাস:** `CategoryController.php`-এর `edit()` মেথড থেকে নির্দিষ্ট ক্যাটাগরি ডাটা ভিউতে পাস করা।


* **এডিট ব্লেড ফাইল তৈরি:** `edit.blade.php` ভিউ ফাইল তৈরি করে লেআউট এক্সটেন্ড করা।


* **সাইডবার ন্যাভিগেশন ঠিক করা:** সাইডবারে ক্যাটাগরি মেনু ও একটিভ ক্লাস ডাইনামিক করা।


* **এডিট ফর্ম ডাইনামিক করা:** ইনপুট ফিল্ডসমূহে ওল্ড ডাটা ও ডাটাবেজের ভ্যালু সেট করা, `@method('PUT')` ও `@csrf` যুক্ত করা।

### ১. ক্যাটাগরি কন্ট্রোলারে এডিট মেথড আপডেট (`CategoryController.php`)

রিসোর্স কন্ট্রোলারের `edit()` মেথডে নির্দিষ্ট ক্যাটাগরি ডাটা ধরে তা ভিউ ফাইলে পাঠাব:

```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\Category;

class CategoryController extends Controller
{
    /**
     * ক্যাটাগরি এডিট ফর্ম প্রদর্শন করা
     */
    public function edit(Category $category)
    {
        // নির্দিষ্ট ক্যাটাগরি ডাটা সহ এডিট ভিউ রিটার্ন করা
        return view('admin.categories.edit', compact('category'));
    }
}

```

### ২. সাইডবার ন্যাভিগেশন লিংক ডাইনামিক করা (`partials/sidebar.blade.php`)

সাইডবার থেকে ক্যাটাগরি পেজে সহজে যাতায়াত এবং একটিভ স্টেট বজায় রাখার জন্য কোড আপডেট করা:

```html
<li class="menu-item {{ request()->routeIs('admin.categories.*') ? 'active' : '' }}">
    <a href="{{ route('admin.categories.index') }}" class="menu-link">
        <i class="menu-icon tf-icons fa-solid fa-folder"></i>
        <div>ক্যাটাগরি</div>
    </a>
</li>

```

### ৩. ক্যাটাগরি এডিট ব্লেড ফাইল (`edit.blade.php`)

এডিট ফর্মে আপডেট রাউট, PUT মেথড এবং বিদ্যমান ডাটা দিয়ে ফিল্ডগুলো ডাইনামিক করা:

```blade
@extends('layouts.admin')

@section('content')
<div class="container-xxl flex-grow-1 container-p-y">
    <!-- ব্যাক বাটন -->
    <a href="{{ route('admin.categories.index') }}" class="btn btn-secondary mb-3">ক্যাটাগরি লিস্ট</a>

    <div class="card mb-4">
        <h5 class="card-header">ক্যাটাগরি এডিট করুন</h5>
        <div class="card-body">
            <!-- এডিট ফর্ম -->
            <form action="{{ route('admin.categories.update', $category->id) }}" method="POST">
                @csrf
                @method('PUT')

                <!-- ক্যাটাগরি নেম -->
                <div class="mb-3">
                    <label class="form-label" for="name">ক্যাটাগরি নাম</label>
                    <input type="text" 
                           class="form-control @error('name') is-invalid @enderror" 
                           id="name" 
                           name="name" 
                           value="{{ old('name', $category->name) }}" />
                    @error('name')
                        <div class="invalid-feedback">{{ $message }}</div>
                    @enderror
                </div>

                <!-- স্লাগ প্রদর্শন (Readonly/Preview) -->
                <div class="mb-3">
                    <label class="form-label">বর্তমান স্লাগ</label>
                    <input type="text" class="form-control" value="{{ $category->slug }}" readonly disabled />
                </div>

                <!-- ডেসক্রিপশন -->
                <div class="mb-3">
                    <label class="form-label" for="description">ডেসক্রিপশন</label>
                    <textarea id="description" name="description" class="form-control">{{ old('description', $category->description) }}</textarea>
                </div>

                <!-- আইকন -->
                <div class="mb-3">
                    <label class="form-label" for="icon">আইকন (Class Name)</label>
                    <input type="text" id="icon" name="icon" class="form-control" value="{{ old('icon', $category->icon) }}" />
                </div>

                <!-- কালার -->
                <div class="mb-3">
                    <label class="form-label" for="color">কালার</label>
                    <input type="color" id="color" name="color" class="form-control" value="{{ old('color', $category->color ?? '#696cff') }}" />
                </div>

                <!-- সর্ট অর্ডার -->
                <div class="mb-3">
                    <label class="form-label" for="sort_order">সর্ট অর্ডার</label>
                    <input type="number" id="sort_order" name="sort_order" class="form-control" value="{{ old('sort_order', $category->sort_order) }}" />
                </div>

                <!-- স্ট্যাটাস (is_active) -->
                <div class="mb-3 form-check">
                    <input type="checkbox" 
                           class="form-check-input" 
                           id="is_active" 
                           name="is_active" 
                           value="1" 
                           {{ old('is_active', $category->is_active) ? 'checked' : '' }}>
                    <label class="form-check-label" for="is_active">সক্রিয় রাখুন</label>
                </div>

                <!-- সাবমিট বাটন -->
                <button type="submit" class="btn btn-primary">আপডেট করুন</button>
            </form>

            <!-- ডিলিট অপশন (পৃথক ফর্ম) -->
            <form action="{{ route('admin.categories.destroy', $category->id) }}" method="POST" class="mt-3">
                @csrf
                @method('DELETE')
                <button type="submit" class="btn btn-danger" onclick="return confirm('আপনি কি নিশ্চিত যে এই ক্যাটাগরি ডিলিট করতে চান?')">
                    ক্যাটাগরি ডিলিট করুন
                </button>
            </form>
        </div>
    </div>
</div>
@endsection

```

### ৪. কাজের মূল বিষয়গুলো

* **`old('field', $category->field)`:** ফর্ম সাবমিট করার পর ভ্যালিডেশন এরর আসলে `old()` ফাংশন ব্যবহারকারীর ইনপুট ধরে রাখবে, অন্যথায় ডাটাবেজের আগের ডাটা দেখাবে।


* **`@method('PUT')`:** এইচটিএমএল ফর্ম সরাসরি `PUT` মেথড সাপোর্ট করে না, তাই লারাভেলের মেথড স্পুফিং এনোটেশন ব্যবহার করে আপডেট রিকোয়েস্ট পাঠাতে হয়।


* **ডিলিট ফর্ম:** এডিট পেজে ডিলিট বাটনটি মূল এডিট ফর্মের ভেতরে না রেখে আলাদা একটি ফর্মে `@method('DELETE')` সহ রাখা হয়েছে, যাতে ভুল রিকোয়েস্ট সাবমিট না হয়।

আজকের ক্লাসে আমরা এডিট ফর্মটি ডাটাবেজের নির্দিষ্ট ডাটা দিয়ে ডাইনামিক করলাম এবং ফর্মের অ্যাকশন আপডেট করলাম।

পরবর্তী পর্বে আমরা **কন্ট্রোলারের `update()` মেথড ডেভেলপ করে এডিটেড ডাটা ডাটাবেজে সেভ করার লজিক** শিখব।
