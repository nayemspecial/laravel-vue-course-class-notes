**প্লাটফর্ম:** প্রযুক্তিপ্লাস একাডেমী (ProjuktiPlus Academy)

**বিষয়:** ১২.৬ ক্যাটাগরি এডিট ফর্মে থাকা বাটন টেক্সট ও ফর্ম লেবেল সঠিক করা, ক্যাটাগরি আপডেট মেথডে ভ্যালিডেশন এবং ডাটা আপডেট লজিক যুক্ত করা, ক্যাটাগরি নাম আপডেট করার সময় বর্তমান ক্যাটাগরির আইডি ইগনোর করার নিয়ম প্রয়োগ করা।

**প্রযুক্তি প্লাস একাডেমির** পক্ষ থেকে আপনাদের সবাইকে স্বাগতম জানাচ্ছি। গত পর্বে আমরা ক্যাটাগরি এডিট করার জন্য ফর্ম তৈরি করেছিলাম এবং সমস্ত ইনপুট ফিল্ড ডাইনামিক করার কাজ সম্পন্ন করেছিলাম। আজকের পর্বে আমরা ক্যাটাগরি এডিট ফর্মের ডাটা ডাটাবেজে আপডেট করার সম্পূর্ণ ব্যাকএন্ড লজিক শিখব।

আজকের ক্লাসের মূল ধাপ ও ফাইলসমূহ:

* **ভিউ ফাইলে কারেকশন:** এডিট ফর্মে থাকা বাটন টেক্সট ও ফর্ম লেবেল সঠিক করা।


* **কন্ট্রোলারে আপডেট লজিক তৈরি:** `CategoryController.php`-এর `update()` মেথডে ভ্যালিডেশন এবং ডাটা আপডেট লজিক যুক্ত করা।


* **ইউনিক ভ্যালিডেশন এক্সেপশন (Unique Rule Exception):** নাম আপডেট করার সময় বর্তমান ক্যাটাগরির আইডি ইগনোর করার নিয়ম প্রয়োগ করা।


* **ডাটা আপডেট ও রিডাইরেক্ট:** `$category->update()` ব্যবহার করে ডাটা সেভ করা এবং মেসেজ সহ রিডাইরেক্ট করা।

### ২. ক্যাটাগরি কন্ট্রোলারে আপডেট লজিক (`CategoryController.php`)

`CategoryController.php`-এর `update()` মেথডটিতে ভ্যালিডেশন ও ডাটা সেভ করার লজিক আপডেট করা:

```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\Category;
use Illuminate\Http\Request;
use Illuminate\Support\Str;

class CategoryController extends Controller
{
    /**
     * ক্যাটাগরি আপডেট করা
     */
    public function update(Request $request, Category $category)
    {
        // ১. ইনপুট ডাটা ভ্যালিডেশন (ইউনিক নেম থেকে নিজের আইডি বাদ দেওয়া)
        $validated = $request->validate([
            'name'        => 'required|string|max:100|unique:categories,name,' . $category->id,
            'description' => 'nullable|string',
            'icon'        => 'nullable|string|max:50',
            'color'       => 'nullable|string|max:20',
            'sort_order'  => 'nullable|integer|min:0',
        ]);

        // ২. ডাটাবেজে ক্যাটাগরি আপডেট করা
        $category->update([
            'name'        => $validated['name'],
            'slug'        => Str::slug($validated['name']), // নাম পরিবর্তন হলে স্লাগও আপডেট হবে
            'description' => $validated['description'] ?? null,
            'icon'        => $validated['icon'] ?? null,
            'color'       => $validated['color'] ?? null,
            'sort_order'  => $validated['sort_order'] ?? 0,
            'is_active'   => $request->boolean('is_active'),
        ]);

        // ৩. ক্যাটাগরি লিস্ট পেজে রিডাইরেক্ট ও সাকসেস মেসেজ
        return redirect()
            ->route('admin.categories.index')
            ->with('success', 'ক্যাটাগরি সফলভাবে আপডেট হয়েছে।');
    }
}

```

### ৪. কাজের মূল বিষয়গুলো

* **`unique:categories,name,' . $category->id`:** ক্যাটাগরির নাম পরিবর্তন না করে সেভ বাটনে চাপ দিলে যেন "The name has already been taken" এরর না আসে, তার জন্য কমা দিয়ে নিজের `$category->id` বাদ দেওয়া হয়েছে।


* **`$category->update([...])`:** মডেল অবজেক্টের সরাসরি `update()` মেথড ব্যবহার করে ইনপুট দেওয়া নতুন ডাটা দিয়ে ডাটাবেজ রেকর্ডটি ওভাররাইট করা হয়েছে।
