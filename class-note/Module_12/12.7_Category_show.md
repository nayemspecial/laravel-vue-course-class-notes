**প্লাটফর্ম:** প্রযুক্তিপ্লাস একাডেমী (ProjuktiPlus Academy)

**বিষয়:** ১২.৭ ক্যাটাগরি কন্ট্রোলারে শো মেথড যোগ করা এবং সেখানে (পোস্ট সংখ্যা, প্রকাশিত অথবা ড্রাফট পোস্ট গণনা এবং সর্বশেষ ১০টি পোস্ট ফেচ করা), ভিউ ফাইল তৈরি করে অ্যাডমিন লেআউট এক্সটেন্ড করা। ও ডাইনামিক করা।

**প্রযুক্তি প্লাস একাডেমির** পক্ষ থেকে আপনাদের সবাইকে স্বাগতম জানাচ্ছি। গত পর্বে আমরা ক্যাটাগরি আপডেট করার ব্যাকএন্ড লজিক সম্পূর্ণ করেছিলাম। আজকের পর্বে আমরা লারাভেলে ক্যাটাগরি ডিটেইলস বা শো পেজ (`show.blade.php`) ডাইনামিক করার সম্পূর্ণ প্রক্রিয়া শিখব।

আজকের ক্লাসের মূল ধাপ ও ফাইলসমূহ:

* **কন্ট্রোলারে ডাটা কোয়েরি:** `CategoryController.php`-এর `show()` মেথডে ক্যাটাগরির পোস্ট সংখ্যা, প্রকাশিত/ড্রাফট পোস্ট গণনা এবং সর্বশেষ ১০টি পোস্ট ফেচ করা।
* **ভিউ ফাইল তৈরি ও লেআউট এক্সটেন্ড:** `admin/categories/show.blade.php` তৈরি করে অ্যাডমিন লেআউট এক্সটেন্ড করা।
* **ক্যাটাগরি ইনফরমেশন ডাইনামিক করা:** ক্যাটাগরির নাম, স্লাগ, কালার, আইকন, সর্ট অর্ডার এবং স্ট্যাটাস কন্ডিশনালি প্রদর্শন করা।
* **সমষ্টিগত ডাটা ও টেবিল লুপ:** পোস্টের পরিসংখ্যান সম্বলিত কার্ড ডাটা ডাইনামিক করা এবং `@forelse` লুপের মাধ্যমে পোস্টের লিস্ট উপস্থাপন করা।

### ১. ক্যাটাগরি কন্ট্রোলারে শো লজিক (`CategoryController.php`)

`CategoryController.php` ফাইলে গিয়ে `show()` মেথডটিতে প্রয়োজনীয় ডাটা কাউন্ট ও কোয়েরির কাজ করা হয়েছে:

```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\Category;

class CategoryController extends Controller
{
    /**
     * ক্যাটাগরি ডিটেইলস ও সম্পর্কিত পোস্ট প্রদর্শন
     */
    public function show(Category $category)
    {
        // ১. ক্যাটাগরির সাথে যুক্ত মোট পোস্ট সংখ্যা কাউন্ট
        $category->loadCount('posts');

        // ২. শুধুমাত্র প্রকাশিত (Published) পোস্ট সংখ্যা কাউন্ট
        $publishedCount = $category->posts()->where('status', 'published')->count();

        // ৩. ড্রাফট (Draft) পোস্ট সংখ্যা কাউন্ট
        $draftCount = $category->posts()->where('status', 'draft')->count();

        // ৪. ক্যাটাগরির সর্বশেষ ১০টি পোস্ট সংগ্রহ
        $posts = $category->posts()->latest()->take(10)->get();

        // ৫. কম্প্যাক্ট করে ভিউ ফাইলে ডাটা পাস করা
        return view('admin.categories.show', compact(
            'category',
            'publishedCount',
            'draftCount',
            'posts'
        ));
    }
}

```

### ৩. গুরুত্বপূর্ণ বিষয়সমূহ

* **`loadCount('posts')`:** ক্যাটাগরির সমস্ত পোস্ট ডাটাবেজ থেকে ওভারলোড না করে শুধুই পোস্টের মোট সংখ্যাটি দক্ষভাবে ফেচ করে।
* **`@forelse ... @empty`:** লুপের মাধ্যমে পোস্ট থাকলে তালিকা প্রদর্শন করে, আর ডাটা খালি থাকলে `@empty` ব্লকের মেসেজ দেখায়।
* **`translatedFormat()`:** কার্বন তারিখকে কাঙ্ক্ষিত ফরম্যাটে ডাইনামিক উপায়ে রূপান্তর করতে ব্যবহৃত হয়েছে।

পরবর্তী পর্বে আমরা **ক্যাটাগরি ডিলিট অপশন (`destroy()` মেথড)** নিয়ে কাজ করব।
