**প্লাটফর্ম:** প্রযুক্তিপ্লাস একাডেমী (ProjuktiPlus Academy)

**বিষয়:** ১২.৮ ক্যাটাগরি কন্ট্রোলারে ডিলিট মেথডে কন্ডিশন ও লজিক যোগ করা, ক্যাটাগরির অধীনে পোস্ট যুক্ত থাকলে ডিলিট করতে বাধা দেওয়া ও সতর্কবার্তা দেখানো, ইন্ডেক্স ভিউ ফাইলে এরর অ্যালার্ট যুক্ত করা।

**প্রযুক্তি প্লাস একাডেমির** পক্ষ থেকে আপনাদের সবাইকে স্বাগতম জানাচ্ছি। গত পর্বে আমরা ক্যাটাগরি ডিটেইলস বা শো পেজ ডাইনামিক করার কাজ সম্পন্ন করেছিলাম। আজকের পর্বে আমরা ক্যাটাগরি CRUD (Create, Read, Update, Delete) অপারেশনের শেষ ধাপ—ক্যাটাগরি ডিলিট বা `destroy()` মেথডের কাজ শিখব।

আজকের ক্লাসের মূল ধাপ ও ফাইলসমূহ:

* **নিরাপত্তা ও ডিপেনডেন্সি চেকিং:** ক্যাটাগরির অধীনে পোস্ট যুক্ত থাকলে ডিলিট করতে বাধা দেওয়া ও সতর্কবার্তা দেখানো।


* **কন্ট্রোলারে ডিলিট লজিক:** `CategoryController.php`-এর `destroy()` মেথডে কন্ডিশন ও ডিলিট অ্যাকশন সেট করা।


* **রিডাইরেক্ট ও নোটিফিকেশন:** সফলতা বা ব্যর্থতার মেসেজ সহ ইন্ডেক্স পেজে রিডাইরেক্ট করা।


* **ইন্ডেক্স ভিউতে এরর মেসেজ হ্যান্ডলিং:** `index.blade.php` ফাইলে এরর সংকেত দেখানোর জন্য সেশন মেসেজ ব্লক যুক্ত করা।

### ১. ক্যাটাগরি কন্ট্রোলারে ডিলিট লজিক (`CategoryController.php`)

ক্যাটাগরি সরাসরি ডিলিট না করে প্রথমে চেক করা হবে তার অধীনে কোনো পোস্ট বিদ্যমান আছে কিনা। যদি পোস্ট থেকে থাকে, তবে ইউজারকে আগে পোস্ট স্থানান্তরের নির্দেশ দিয়ে ডিলিট ব্লক করা হবে:

```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\Category;

class CategoryController extends Controller
{
    /**
     * ক্যাটাগরি ডিলিট করা
     */
    public function destroy(Category $category)
    {
        // ১. চেক করা ক্যাটাগরির অধীনে কোন পোস্ট আছে কিনা
        if ($category->posts()->exists()) {
            return redirect()
                ->route('admin.categories.index')
                ->with('error', 'এই ক্যাটাগরির অধীনে পোস্ট থাকায় ক্যাটাগরিটি ডিলিট করা যাচ্ছে না। আগে পোস্ট অন্য ক্যাটাগরিতে সরিয়ে নিন।');
        }

        // ২. পোস্ট না থাকলে ক্যাটাগরি ডিলিট করা
        $category->delete();

        // ৩. সফলতা বার্তা সহ ইন্ডেক্স পেজে রিডাইরেক্ট
        return redirect()
            ->route('admin.categories.index')
            ->with('success', 'ক্যাটাগরি সফলভাবে ডিলিট করা হয়েছে।');
    }
}

```

### ২. ইন্ডেক্স ভিউ ফাইলে এরর অ্যালার্ট যুক্ত করা (`index.blade.php`)

ক্যাটাগরি লিস্ট পেজে সাকসেস মেসেজের পাশাপাশি এরর মেসেজ প্রদর্শনের ব্যবস্থা করা:

```blade
<!-- সাকসেস মেসেজ -->
@if(session('success'))
    <div class="alert alert-success alert-dismissible fade show" role="alert">
        {{ session('success') }}
        <button type="button" class="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>
    </div>
@endif

<!-- এরর মেসেজ -->
@if(session('error'))
    <div class="alert alert-danger alert-dismissible fade show" role="alert">
        {{ session('error') }}
        <button type="button" class="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>
    </div>
@endif

```

### ৩. গুরুত্বপূর্ণ লজিক্যাল বিষয়সমূহ

* **`$category->posts()->exists()`:** ডাটাবেজ থেকে সমস্ত পোস্ট লোড না করে খুব দ্রুত চেক করে যে এই আইডি সম্পর্কিত কোনো রেকর্ড `posts` টেবিলে আছে কিনা।


* **ডাটা ইনটিগ্রিটি (Data Integrity):** ভুলবশত কোনো ক্যাটাগরি মুছে ফেলে যেন তার আন্ডারে থাকা পোস্টগুলো অরফ্যান (Orphan) না হয়ে যায়, সেজন্য এই চেকিং অত্যন্ত জরুরি।

আজকের ক্লাসের মাধ্যমে আমাদের ক্যাটাগরি মডিউলের সম্পূর্ণ CRUD (ক্রিয়েট, রিড, আপডেট, ডিলিট) অপারেশন সফলভাবে শেষ হলো।

পরবর্তী পর্ব থেকে আমরা **পোস্ট ম্যানেজমেন্ট (Post Management)** অথবা **কমেন্ট সিস্টেম (Comments System)** নিয়ে কাজ শুরু করব।
