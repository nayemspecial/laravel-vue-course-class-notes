**প্লাটফর্ম:** প্রযুক্তিপ্লাস একাডেমী (ProjuktiPlus Academy)

**বিষয়:** ১৩.১ ক্যাটাগরি কন্ট্রোলারে ডিলিট মেথডে কন্ডিশন ও লজিক যোগ করা, ক্যাটাগরির অধীনে পোস্ট যুক্ত থাকলে ডিলিট করতে বাধা দেওয়া ও সতর্কবার্তা দেখানো, ইন্ডেক্স ভিউ ফাইলে এরর অ্যালার্ট যুক্ত করা।

**প্রযুক্তি প্লাস একাডেমির** পক্ষ থেকে আপনাদের সবাইকে স্বাগতম জানাচ্ছি। আজকের পর্বে আমরা লারাভেলে ব্লগ প্রজেক্টের **কমেন্ট মডারেশন (Comment Moderation)** মডিউল সেটআপ এবং এর আর্কিটেকচার নিয়ে আলোচনা শুরু করব।

আজকের ক্লাসের মূল বিষয়বস্তু:

* **কমেন্ট মডারেশনের মেথড অ্যানালাইসিস:** কেন কমেন্ট মডারেশনে স্ট্যান্ডার্ড ৭টি CRUD মেথড ব্যবহার করা হবে না।


* **কাস্টম রাউটিং সেটআপ:** `web.php`-এ কমেন্ট মডারেশনের জন্য গেট (GET) রাউট তৈরি করা।


* **কন্ট্রোলার ক্রিয়েশন:** `Admin/CommentController.php` তৈরি করা।


* **ভিউ ফাইল ও সিএসএস লিংকআপ:** `comments/index.blade.php` ভিউ ফাইল তৈরি করে মাস্টার লেআউট এক্সটেন্ড করা।

### ১. কমেন্ট মডারেশন আর্কিটেকচার (কেন প্রচলিত CRUD নয়?)

সাধারণত লারাভেল রিসোর্স রাউটে ৭টি মেথড (`index`, `create`, `store`, `show`, `edit`, `update`, `destroy`) থাকে। তবে কমেন্ট মডারেশনের ক্ষেত্রে লজিকটি কিছুটা ভিন্ন:

* **`create` ও `store` মেথডের প্রয়োজন নেই:** কমেন্ট সচরাচর অ্যাডমিন নিজে তৈরি করেন না, পাঠকরা (Readers) ফ্রন্টএন্ড থেকে পাঠান।


* **`edit` ও `update` মেথডের প্রয়োজন নেই:** পাঠকদের মন্তব্য অ্যাডমিন পরিবর্তন বা এডিট করেন না।


* **`show` মেথডের প্রয়োজন নেই:** কমেন্টের সমস্ত তথ্য (পোস্ট টাইটেল, রিপ্লাই ইত্যাদি) ইন্ডেক্স লিস্ট পেজেই বিস্তারিতভাবে প্রদর্শিত হবে।


* **প্রয়োজনীয় মেথড (মোট ৪টি):**
1. `index` (সকল কমেন্ট দেখার জন্য)


2. `approve` (কমেন্ট অনুমোদন করার জন্য)


3. `reject` (কমেন্ট রিজেক্ট বা বাতিল করার জন্য)


4. `destroy` (কমেন্ট স্থায়ীভাবে ডিলিট করার জন্য)

### ২. কাস্টম রাউট সেটআপ (`routes/web.php`)

যেহেতু রিসোর্সের সব মেথড লাগবে না, তাই আমরা কাস্টম রাউট ব্যবহার করছি:

```php
use App\Http\Controllers\Admin\CommentController;

Route::prefix('admin')->name('admin.')->group(function () {
    // কমেন্ট মডারেশন লিস্ট রাউট
    Route::get('/comments', [CommentController::class, 'index'])->name('comments.index');
});

```

### ৩. কন্ট্রোলার তৈরি (`CommentController.php`)

টার্মিনালে কমান্ডটি রান করে অ্যাডমিন ফোল্ডারে কন্ট্রোলার তৈরি করি (এখানে `--resource` ফ্ল্যাগ ব্যবহার করা হয়নি):

```bash
php artisan make:controller Admin/CommentController

```

কন্ট্রোলারে `index()` মেথড তৈরি করে ভিউ রিটার্ন করার লজিক:

```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use Illuminate\Http\Request;

class CommentController extends Controller
{
    /**
     * সকল কমেন্টের তালিকা ও মডারেশন পেজ
     */
    public function index()
    {
        return view('admin.comments.index');
    }
}

```

### ৫. গুরুত্বপূর্ণ বিষয়সমূহ

* **রেসপন্সিবিলিটি পৃথকীকরণ:** বাস্তবমুখী প্রজেক্ট ডেভেলপমেন্টে অপ্রয়োজনীয় মেথড এড়িয়ে প্রয়োজনীয় মেথড দিয়ে ক্লিন আর্কিটেকচার বজায় রাখা ভালো প্র্যাকটিস।


* **স্ট্যাটিক সিএসএস ইন্টিগ্রেশন:** কাস্টম ডিজাইন বা ব্যাজ (Pending, Approved) ব্যবহারের জন্য প্রয়োজনীয় সিএসএস ক্লাসগুলো `app.css` ফাইলে যুক্ত করতে হবে।

আজকের পর্বে আমরা কমেন্ট মডারেশন মডিউলের প্রাথমিক স্ট্রাকচার, রাউটিং এবং ভিউ লোডিং সম্পন্ন করেছি।

পরবর্তী পর্বে আমরা **ডাটাবেজ থেকে আসল কমেন্ট ডাটা ফেচ করা এবং কমেন্ট অনুমোদন (`approve`) ও বাতিল (`reject`) করার ব্যাকএন্ড লজিক** ডেভেলপ করব।
