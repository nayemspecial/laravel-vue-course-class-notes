**প্লাটফর্ম:** প্রযুক্তিপ্লাস একাডেমী (ProjuktiPlus Academy)

**বিষয়:** ১৩.২ কমেন্ট কন্ট্রোলারে কোয়েরি বিল্ডার ব্যবহার করে ডাটাবেজ থেকে কমেন্ট ডাটা ফিল্টারিং, ইগার লোডিং N+1 প্রবলেম সমাধান, পেন্ডিং ফিল্টার, অপ্রুভড ফিল্টার, পেজিনেশন, প্রতি ক্ষেত্রে সংক্যা গণনা, সকল ডাটা ভিউ ফাইলে পাঠানো।

**প্রযুক্তি প্লাস একাডেমির** পক্ষ থেকে আপনাদের সবাইকে স্বাগতম জানাচ্ছি। গত পর্বে আমরা কমেন্ট মডারেশন মডিউলের জন্য কাস্টম রাউটিং, কন্ট্রোলার এবং ভিউ ফাইলের প্রাথমিক সেটআপ সম্পন্ন করেছিলাম।

আজকের পর্বে আমরা **কমেন্ট কন্ট্রোলারে কোয়েরি বিল্ডার (Query Builder) ও ইগার লোডিং (Eager Loading)** ব্যবহার করে ডাটাবেজ থেকে কমেন্ট ডাটা ফিল্টারিং, পেজিনেশন এবং স্ট্যাটাস অনুযায়ী কাউন্টিংয়ের ব্যাকএন্ড লজিক বাস্তবায়ন করা শিখব।

আজকের ক্লাসের মূল বিষয়বস্তু:

* **রিকোয়েস্ট থেকে কোয়েরি প্যারামিটার হ্যান্ডলিং:** URL এর `status` অনুযায়ী ডাটা ফিল্টারিং।


* **ইগার লোডিং (Eager Loading):** N+1 প্রবলেম সমাধানের জন্য `with()` মেথডের ব্যবহার।


* **শর্তসাপেক্ষ কোয়েরি (`when()` ও Arrow Function):** লারাভেলের `when()` মেথড দিয়ে পেন্ডিং ও অপ্রুভড কমেন্ট ফিল্টার করা।


* **ডাটা কাউন্ট ও পেজিনেশন:** পেন্ডিং ও অপ্রুভড কমেন্টের সংখ্যা হিসাব এবং `paginate()` মেথড ব্যবহার।


* **`compact()` মেথডে ভিউতে ডাটা পাস:** ভেরিয়াবলগুলো ব্লেড ভিউ ফাইলে পাঠানো।

### ১. কমেন্ট কন্ট্রোলার লজিক (`Admin/CommentController.php`)

আমাদের `CommentController.php` ফাইলে `index()` মেথডের ভেতর ব্যাকএন্ড লজিকগুলো ধাপে ধাপে আপডেট করি:

```php
namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\Comment;
use Illuminate\Http\Request;

class CommentController extends Controller
{
    /**
     * কমেন্ট তালিকা, ফিল্টারিং ও কাউন্ট লোড করা
     */
    public function index(Request $request)
    {
        // ১. ইউআরএল থেকে স্ট্যাটাস কোয়েরি প্যারামিটার নেওয়া (যেমন: ?status=pending)
        $status = $request->query('status');

        // ২. কমেন্ট কোয়েরি ও ইগার লোডিং (N+1 সমস্যা এড়াতে)
        $comments = Comment::with(['post', 'user', 'parent'])
            // পেন্ডিং ফিল্টার কন্ডিশন
            ->when($status === 'pending', fn($q) => $q->where('is_approved', false))
            // অপ্রুভড ফিল্টার কন্ডিশন
            ->when($status === 'approved', fn($q) => $q->where('is_approved', true))
            // সর্বশেষ কমেন্ট আগে দেখানোর জন্য
            ->latest()
            // প্রতি পেজে ১৫টি করে পেজিনেশন
            ->paginate(15);

        // ৩. পেন্ডিং কমেন্টের মোট সংখ্যা গণনা (is_approved = false)
        $pendingCount = Comment::where('is_approved', false)->count();

        // ৪. অনুমোদিত (Approved) কমেন্টের মোট সংখ্যা গণনা (is_approved = true)
        $approvedCount = Comment::where('is_approved', true)->count();

        // ৫. সকল ডাটা ভিউ ফাইলে পাঠানো
        return view('admin.comments.index', compact(
            'comments',
            'status',
            'pendingCount',
            'approvedCount'
        ));
    }
}

```

### ২. লজিক্যাল টেকনিক্যাল বিশ্লেষণ

* **ইগার লোডিং `with(['post', 'user', 'parent'])`:** কমেন্টের সাথে সম্পর্কযুক্ত পোস্ট, ইউজার এবং প্যারেন্ট কমেন্টের ডাটা একসাথে লোড করে। এতে ডাটাবেজে বার বারবার অতিরিক্ত কোয়েরি চলা (N+1 Query Problem) বন্ধ হয় এবং অ্যাপ্লিকেশন ফাস্ট হয়।


* **`when()` ও Arrow Function (`fn()`):** ইউআরএল-এ যদি `status=pending` আসে, তবে কেবল `is_approved = false` কমেন্টগুলো ফিল্টার হয়ে আসবে। আর `status=approved` হলে `is_approved = true` ফিল্টার হবে। কোনো স্ট্যাটাস না থাকলে সব কমেন্ট একসাথে দেখাবে।


* **`paginate(15)`:** ডাটাবেজ থেকে সব ডাটা একসাথে লোড না করে পেজ আকারে ১৫টি করে লোড করবে।


* **`count()`:** ড্যাশবোর্ডের ফিল্টার ট্যাবে বা ব্যাজে (Pending / Approved) মোট সংখ্যা দেখানোর জন্য ডাটা কাউন্ট করা হয়েছে।

আজকের ক্লাসে আমরা কমেন্ট মডারেশন ড্যাশবোর্ডের প্রয়োজনীয় সকল ব্যাকএন্ড ফিল্টারিং ও কোয়েরি লজিক সফলভাবে সম্পন্ন করেছি।

পরবর্তী পর্বে আমরা **`index.blade.php` ফাইলে গিয়ে `@foreach` লুপ চালিয়ে ডাটাগুলো ডাইনামিকভাবে ডিসপ্লে করব এবং পেজিনেশন লিংক যুক্ত করব**।
