প্রিয় শিক্ষার্থীবৃন্দ,

আজকের ক্লাসে সবাইকে স্বাগতম। গত পর্বে আমরা কমেন্ট ফিল্টারিং ট্যাবের কাজগুলো শেষ করেছিলাম।

আজকের পর্বে আমরা **সাইডবার নেভিগেশন অ্যাক্টিভ করা, কমেন্ট অ্যাকশন বাটনসমূহ (Approve, Reject, Delete)-এর জন্য ডাইনামিক রাউটিং, কন্ট্রোলার লজিক তৈরি এবং পেজিনেশন (Pagination) যুক্ত করা** শিখব।

---

### আজকের ক্লাসের মূল বিষয়বস্তু

* **সাইডবার ডাইনামিককরণ:** বর্তমানে কমেন্ট সেকশনে থাকলেও সাইডবারে 'Comments' মেনুটি অ্যাক্টিভ ছিল না। সেটি ডাইনামিক করা।


* **কাস্টম রাউটিং (`routes/web.php`):** কমেন্ট Approve, Reject এবং Delete করার জন্য `PATCH` ও `DELETE` মেথড ব্যবহার করে রাউট তৈরি।


* **কন্ট্রোলার লজিক (`CommentController.php`):** ডাটাবেজের `is_approved` কলাম আপডেট করা এবং রেপোর্টিং মেসেজ সহ রিডাইরেক্ট করা।


* **ব্লেড ফ্রন্টএন্ড ফর্ম ও বাটন অ্যাকশন (`index.blade.php`):** টেবিলের ভেতরে ফর্ম টোকেন (@csrf) ও মেথড স্পেসিফায়ার সহ বাটন সেটআপ।


* **লারাভেল পেজিনেশন (`hasPages()` ও `links()`):** কমেন্ট লিস্টের নিচে পেজিনেশন বার যুক্ত করা।

### ১. সাইডবার অ্যাক্টিভ স্টেট ডাইনামিককরণ

`resources/views/layouts/sidebar.blade.php` ফাইলে কমেন্ট মেনুটিকে রাউট অনুসারে অ্যাক্টিভ করতে নিচের মতো আপডেট করুন:

```blade
<li class="{{ request()->routeIs('comments.*') ? 'active' : '' }}">
    <a href="{{ route('comments.index') }}">
        <i class="fa fa-comments"></i>
        <span>Comments</span>
    </a>
</li>

```

### ২. রাউট ডিক্লেয়ারেশন (`routes/web.php`)

যেহেতু এপ্রুভ এবং রিজেক্ট করলে শুধু একটি ফিল্ড নির্দিষ্টভাবে পরিবর্তিত হয়, তাই `PATCH` মেথড ব্যবহার করা হয়েছে:

```php
use App\Http\Controllers\CommentController;

// Comment Action Routes
Route::patch('/comments/{comment}/approve', [CommentController::class, 'approve'])->name('comments.approve');
Route::patch('/comments/{comment}/reject', [CommentController::class, 'reject'])->name('comments.reject');
Route::delete('/comments/{comment}', [CommentController::class, 'destroy'])->name('comments.destroy');

```

### ৩. কন্ট্রোলার লজিক তৈরি (`CommentController.php`)

কমেন্ট মডারেশন সম্পন্ন করতে তিনটি নতুন মেথড যুক্ত করুন:

```php
namespace App\Http\Controllers;

use App\Models\Comment;
use Illuminate\Http\Request;

class CommentController extends Controller
{
    // ১. কমেন্ট এপ্রুভ মেথড
    public function approve(Comment $comment)
    {
        $comment->update(['is_approved' => true]);

        return redirect()->back()->with('success', 'কমেন্ট এপ্রুভ করা হয়েছে।');
    }

    // ২. কমেন্ট রিজেক্ট মেথড
    public function reject(Comment $comment)
    {
        $comment->update(['is_approved' => false]);

        return redirect()->back()->with('success', 'কমেন্ট রিজেক্ট করা হয়েছে।');
    }

    // ৩. কমেন্ট ডিলিট মেথড
    public function destroy(Comment $comment)
    {
        $comment->delete();

        return redirect()->back()->with('success', 'কমেন্ট ডিলিট করা হয়েছে।');
    }
}

```

### ৪. ব্লেড ভিউতে অ্যাকশন বাটন সেটআপ (`comments/index.blade.php`)

কমেন্ট টেবিলের শেষ কলামে বাটনগুলোর জন্য ফর্ম ট্যাগ ও ফন্ট-অসাম আইকন যুক্ত করুন:

```blade
<td class="text-end d-flex gap-1 justify-content-end">
    <!-- এপ্রুভ বাটন -->
    <form action="{{ route('comments.approve', $comment->id) }}" method="POST">
        @csrf
        @method('PATCH')
        <button type="submit" class="btn btn-sm icon-action-success" title="Approve">
            <i class="fa-solid fa-circle-check"></i>
        </button>
    </form>

    <!-- রিজেক্ট বাটন -->
    <form action="{{ route('comments.reject', $comment->id) }}" method="POST">
        @csrf
        @method('PATCH')
        <button type="submit" class="btn btn-sm icon-action" title="Reject">
            <i class="fa-solid fa-circle-xmark"></i>
        </button>
    </form>

    <!-- ডিলিট বাটন -->
    <form action="{{ route('comments.destroy', $comment->id) }}" method="POST">
        @csrf
        @method('DELETE')
        <button type="submit" class="btn btn-sm icon-action-danger" onclick="return confirm('আপনি কি নিশ্চিত?')" title="Delete">
            <i class="fa-solid fa-trash"></i>
        </button>
    </form>
</td>

```

### ৫. ডাটাবেজ খালি স্টেট ও পেজিনেশন যুক্ত করা

ডাটা না থাকলে খালি বার্তা দেখাতে `@empty` ব্লক এবং ডাটার একাধিক পৃষ্ঠা হ্যান্ডেল করতে ব্লেড ডাইরেক্টভ যুক্ত করুন:

```blade
<!-- টেবিল বডির ভেতরে খালি অবস্থা -->
@empty
    <tr>
        <td colspan="4" class="text-center py-4 text-muted">
            এখনো কোন কমেন্ট তৈরি করা হয়নি।
        </td>
    </tr>
@endforelse

<!-- টেবিলের বাইরে নিচে পেজিনেশন লিংক -->
@if($comments->hasPages())
    <div class="mt-3 d-flex justify-content-end">
        {{ $comments->links() }}
    </div>
@endif

```

### টেকনিক্যাল টিপস

* **HTTP Methods:** ডাটাবেজের সম্পূর্ণ রো রিমুভ না করে নির্দিষ্ট কলাম পরিবর্তন করতে `PATCH` মেথড ব্যবহার করা বেস্ট প্র্যাকটিস।


* **Route Model Binding:** কন্ট্রোলারে `Comment $comment` ব্যবহার করায় লারাভেল আইডি অনুযায়ী মডেল থেকে স্বয়ংক্রিয়ভাবে ডাটা ফেচ করে নেয়।


* **UI Responsiveness:** টেবিল ব্যাজ ও আইকনের জন্য `padding` সামঞ্জস্য রেখে টেবিল লেআউট ভাঙা রোধ করা হয়েছে।



আজকের ক্লাসে আমরা সাকসেসফুলি কমেন্ট অ্যাকশন এবং পেজিনেশন কমপ্লিট করেছি। পরবর্তী ক্লাসে আমরা নতুন ফিচার নিয়ে আলোচনা করব।
