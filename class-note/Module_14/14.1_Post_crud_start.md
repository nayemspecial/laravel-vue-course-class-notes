প্রিয় শিক্ষার্থীবৃন্দ,

আজকের ক্লাসে সবাইকে স্বাগতম। গত পর্বে আমরা কমেন্ট সেকশনের মডারেশন, ডাইনামিক বাটন, ফিল্টারিং ও পেজিনেশন সফলভাবে শেষ করেছিলাম।

আজকের পর্বে আমরা **পোস্ট ম্যানেজমেন্ট ক্রাড (CRUD) অপারেশনের ভিত্তি স্থাপন, লারাভেল রিসোর্স রাউটিং এবং ব্লেড ভিউ টেমপ্লেট ডাইনামিক করা** শিখব।

---

**আজকের ক্লাসের মূল বিষয়বস্তু**

* **রিসোর্স রাউট রিভিউ ও মেকানিজম:** লারাভেলের ৭টি ডিফল্ট ক্রাড মেথড কীভাবে কাজ করে তার রিভিশন।


* **পোস্ট রিসোর্স রাউট ডিক্লেয়ারেশন (`routes/web.php`):** পোস্টের জন্য সংক্ষেপে রিসোর্স রাউট গঠন।


* **রিসোর্স কন্ট্রোলার তৈরি (`PHP Artisan`):** কমান্ড লাইনের মাধ্যমে ব্লুপ্রিন্ট সহ `PostController` জেনারেট করা।


* **মডেল বাইন্ডিং সেটআপ:** কন্ট্রোলারের মেথডগুলোতে টাইপ-হিন্টিং এর মাধ্যমে মডেল বাইন্ডিং নিশ্চিত করা।


* **ব্লেড ভিউ ও লেআউট এক্সটেন্ড:** মাস্টার অ্যাপ লেআউটের সাথে পোস্টের `index.blade.php` অ্যাটাচ করা।


* **সাইডবার অ্যাক্টিভ স্টেট ডাইনামিককরণ:** সাইডবার মেনুতে পোস্ট সেকশনকে সক্রিয় করা।



---

**১. রিসোর্স রাউট মেকানিজম (Resource Route Structure)**

লারাভেলে একটি রিসোর্স রাউট ব্যাকএন্ডে মোট ৭টি আলাদা রাউট মেইনটেইন করে:

* **`index` (GET):** সকল পোস্টের লিস্ট দেখানোর জন্য।


* **`create` (GET):** নতুন পোস্ট তৈরির ফর্ম প্রদর্শনের জন্য।


* **`store` (POST):** ফর্মে ইনপুটকৃত ডাটা ডাটাবেজে সেভ করার জন্য।


* **`show` (GET):** নির্দিষ্ট একটি সিঙ্গেল পোস্টের বিস্তারিত দেখার জন্য।


* **`edit` (GET):** বিদ্যমান পোস্টের এডিট ফর্ম দেখানোর জন্য।


* **`update` (PUT/PATCH):** এডিট করা ডাটা পুনরায় আপডেট করার জন্য।


* **`destroy` (DELETE):** নির্দিষ্ট ডাটা মুছে ফেলার জন্য।



---

**২. রাউট ডিক্লেয়ারেশন (`routes/web.php`)**

যেহেতু আমাদের রাউট গ্রুপে অ্যাডমিন প্রিফিক্স এবং নেমিং অ্যাড করা আছে, তাই পোস্টের জন্য রিসোর্স রাউট হবে:

```php
use App\Http\Controllers\Admin\PostController;

// Post Management Resource Route
Route::resource('posts', PostController::class);

```

---

**৩. রিসোর্স কন্ট্রোলার তৈরি (Artisan Command)**

কমান্ড লাইনে নিচের কমান্ডটি চালিয়ে আমরা `Admin` ফোল্ডারের ভেতর ৭টি ডিফল্ট মেথডসহ একটি রিসোর্স কন্ট্রোলার তৈরি করব:

```bash
php artisan make:controller Admin/PostController --resource

```

**৪. মডেল বাইন্ডিং (Route Model Binding Setup)**

কন্ট্রোলার ফাইলে ম্যানুয়াল আইডি পাস না করে সরাসরি মডেল বাইন্ডিং করা লারাভেলের বেস্ট প্র্যাকটিস। `PostController.php` ফাইলে সং সং শ্লিষ্ট মেথডগুলো নিচের মতো আপডেট করুন:

```php

use App\Http\Controllers\Controller;
use App\Models\Post;
use Illuminate\Http\Request;

class PostController extends Controller
{
    public function index()
    {
        return view('admin.posts.index');
    }

        // Single post view logic
    }

    public function edit(Post $post)
    {
        // Edit post logic
    }

    public function update(Request $request, Post $post)
    {
        // Update post logic
    }

    public function destroy(Post $post)
    {
        // Delete post logic
    }
}

```

**৫. ব্লেড ভিউ ফাইল তৈরি ও অ্যাপ লেআউট এক্সটেন্ড (`admin/posts/index.blade.php`)**

`resources/views/admin/posts/index.blade.php` ফাইল তৈরি করে মূল ড্যাশবোর্ডের মাস্টার লেআউট এক্সটেন্ড করুন:

```blade
@extends('layouts.admin.app')

@section('content')
<main class="content">
    <div class="container-fluid p-0">
        <h1 class="h3 mb-3">Post Management</h1>
        
        <!-- Post List Table Content -->
        
    </div>
</main>
@endsection

```

**৬. সাইডবার অ্যাক্টিভ স্টেট ডাইনামিককরণ (`sidebar.blade.php`)**

সাইডবারে পোস্ট লিংক অ্যাক্টিভ রাখতে এবং ডাইনামিক করতে নিচের মতো কোড যুক্ত করুন:

```blade
<li class="sidebar-item {{ request()->routeIs('posts.*') ? 'active' : '' }}">
    <a class="sidebar-link" href="{{ route('admin.posts.index') }}">
        <i class="fa-solid fa-newspaper align-middle"></i> 
        <span class="align-middle">পোস্ট সমূহ</span>
    </a>
</li>

```

**টেকনিক্যাল টিপস**

* **Route Prefixes:** রাউট গ্রুপে প্রিফিক্স যুক্ত থাকলে রিসোর্স রাউটের নাম নির্ধারণে পুনরায় বার বার প্রিফিক্স লেখার প্রয়োজন পড়ে না।


* **Clean Layout:** ভিউ ফাইলে রিডানড্যান্ট বা ডুপ্লিকেট `<main>` ট্যাগ ব্যবহার না করে শুধু মাস্টার লেআউটের নির্ধারিত `@section('content')`-এর ভেতরের অংশটুকু স্ট্রাকচার্ড করা উচিত।



আজকের ক্লাসে আমরা পোস্ট সেকশনের ব্যাকএন্ড রাউটিং, কন্ট্রোলার ও ফ্রন্টএন্ড লেআউট সেটআপ সম্পন্ন করেছি। পরবর্তী পর্বে আমরা পোস্ট টেবিলের টাইটেল, ক্যাটাগরি ও ট্যাগ ডাটাবেজ থেকে রিভ করার মাধ্যমে ডাইনামিক করা শিখব।
