প্রিয় শিক্ষার্থীবৃন্দ,

আজকের ক্লাসে আপনাদের সবাইকে স্বাগতম। বিগত পর্বে আমরা এডমিন ড্যাশবোর্ডের পোস্ট ম্যানেজমেন্ট ইনডেক্স পেজে তালিকা ডাইনামিক করা সম্পন্ন করেছিলাম।

আজকের ক্লাসের বিস্তারিত নোট নিচে উপস্থাপন করা হলো:

---

### **১. ইনডেক্স পেজে লারাভেল পেজিনেশন (Pagination) যোগকরণ**

গত পর্বে আমাদের পোস্ট লিস্টের নিচে পেজিনেশন বাকি ছিল। লারাভেলের বিল্ট-ইন পেজিনেশন ব্যবহার করে এটি সহজে যুক্ত করা হয়েছে।

* **ব্লেড কোড পরিবর্তন:** স্ট্যাটিক স্প্যান (`<span>`) ট্যাগগুলো সরিয়ে লারাভেলের `links()` মেথড রেন্ডার করা হয়েছে:


```blade
{{ $posts->links() }}

```


* **লেআউট ক্লিনআপ:** অতিরিক্ত কাউন্ট/টেক্সট এবং Flex layout-এর `justify-between` জনিত সমস্যা দূর করতে অপ্রয়োজনীয় প্যারাগ্রাফ ট্যাগ মুছে ফেলা হয়েছে, যাতে পেজিনেশন লিংকগুলো সেন্টার-অ্যালাইন থাকে।



---

### **২. পোস্ট ক্রিয়েট পেজের রাউট, কন্ট্রোলার ও ভিউ সেটআপ**

পোস্ট তৈরির ফর্ম প্রদর্শনের জন্য প্রয়োজনীয় ধাপগুলো বাস্তবায়ন করা হয়েছে:

1. **স্ট্যাটিক টেমপ্লেট এক্সটেন্ড করা:**
`resources/views/admin/posts/create.blade.php` ফাইল তৈরি করে মাস্টার লেআউট এক্সটেন্ড এবং কন্টেন্ট সেকশন ডিফাইন করা হয়েছে:


```blade
@extends('admin.layouts.app')

@section('content')
    <!-- Post Create Form Code -->
@endsection

```


2. **কন্ট্রোলার মেথড (`PostController.php`):**
`create` মেথডের মাধ্যমে ক্রিয়েট ভিউ ফাইল রিটার্ন করা হয়েছে:


```php
public function create()
{
    return view('admin.posts.create');
}

```



---

### **৩. ক্রিয়েট ফর্মে ডাটাবেজ থেকে ক্যাটাগরি ও ট্যাগ ডাটা পাস করা**

পোস্ট ডাইনামিক করার জন্য ডাটাবেজ থেকে অ্যাক্টিভ ক্যাটাগরি এবং ক্রমানুসারে সাজানো ট্যাগ কন্ট্রোলার থেকে ভিউ-তে পাঠানো হয়েছে:

* **`PostController.php` আপডেট:**
```php
use App\Models\Category;
use App\Models\Tag;

public function create()
{
    $categories = Category::where('status', 'active')->orderBy('name')->get();
    $tags = Tag::orderBy('name')->get();

    return view('admin.posts.create', compact('categories', 'tags'));
}

```

### **৪. ক্রিয়েট ব্লেড ফর্ম এবং ভ্যালিডেশন ডায়নামিককরণ (`create.blade.php`)**

ফর্মে ডাটা সাবমিট, সিএসআরএফ প্রটেকশন এবং ভ্যালিডেশন এরর মেসেজ প্রদর্শনের স্ট্রাকচার তৈরি করা হয়েছে:

1. **ফর্মে অ্যাকশন ও মেথড সেটআপ:**
```blade
<form action="{{ route('admin.posts.store') }}" method="POST" enctype="multipart/form-data">
    @csrf
    <!-- Form Fields -->
</form>

```


(নোট: ফাইল আপলোডের জন্য `enctype="multipart/form-data"` ব্যবহার করা অবশ্যম্ভাবী।)


2. **ইনপুট ফিল্ড ও ওল্ড ডাটা রিটেনশন (Old Value & Error Handling):**
* **টাইটেল ইনপুট:**
```blade
<input type="text" name="title" value="{{ old('title') }}" class="form-control @error('title') is-invalid @enderror">
@error('title')
    <span class="text-danger">{{ $message }}</span>
@enderror

```


* **এক্সার্ট (সংক্ষিপ্ত বিবরণ) ইনপুট:**
```blade
<textarea name="excerpt" class="form-control @error('excerpt') is-invalid @enderror">{{ old('excerpt') }}</textarea>
@error('excerpt')
    <span class="text-danger">{{ $message }}</span>
@enderror

```


* **মূল কন্টেন্ট ইনপুট:**
```blade
<textarea name="content" class="form-control @error('content') is-invalid @enderror">{{ old('content') }}</textarea>
@error('content')
    <span class="text-danger">{{ $message }}</span>
@enderror

```

**আজকের সারসংক্ষেপ:**
আমরা সফলভাবে পোস্ট ইনডেক্সে পেজিনেশন যুক্ত করেছি, ক্রিয়েট ভিউ রেন্ডার করেছি এবং টাইটেল, এক্সার্ট ও কন্টেন্ট ফিল্ডের সাথে ওল্ড ডাটা ও ভ্যালিডেশন এরর হ্যান্ডলিং সেটআপ করেছি। পরবর্তী ক্লাসে আমরা ড্রপডাউন থেকে ক্যাটাগরি নির্বাচন, চেকবক্স ট্যাগ ও ফাইল আপলোডের কাজ বাকি অংশ থেকে ডাইনামিক করা শিখব।
