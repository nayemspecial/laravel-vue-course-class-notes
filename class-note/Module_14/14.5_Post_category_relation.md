প্রিয় শিক্ষার্থীবৃন্দ,

আজকের ক্লাসে আপনাদের সবাইকে স্বাগতম! গত পর্বে আমরা পোস্ট ক্রিয়েশনের সাধারণ ইনপুট ফিল্ডসমূহ সেটআপ করেছিলাম।

আজকের পর্বে আমরা **পোস্ট ক্রিয়েট ফর্মে ক্যাটাগরি রিলেশনশিপ, স্ট্যাটাস অপশন, ট্যাগ অ্যারে নির্বাচন, ফিচারড ইমেজ ফাইল আপলোড কনফিগারেশন এবং ফর্ম ডেটা ডেভ-টেস্টিং** বিস্তারিত আলোচনা করব।

আজকের ক্লাসের বিস্তারিত লেকচার নোট নিচে উপস্থাপন করা হলো:

---

### **১. ক্যাটাগরি ড্রপডাউন ডাইনামিককরণ ও ওল্ড ডাটা রিটেনশন**

ডাটাবেজে পোস্ট টেবিলের সাথে ক্যাটাগরি টেবিলের রিলেশনশিপ বজায় রাখতে `category_id` ফিল্ডটি ব্যবহার করা হয়।

* **লুপ ও সিলেক্টেড লজিক:** কন্ট্রোলার থেকে আসা `$categories` কালেকশনকে লুপ করে অপশন রেন্ডার করা হয়েছে এবং ফর্মে ভুল হলে আগের সিলেক্ট করা ক্যাটাগরি ধরে রাখার ব্যবস্থা করা হয়েছে।



```blade
<select name="category_id" class="form-control @error('category_id') is-invalid @enderror">
    <option value="">ক্যাটাগরি নির্বাচন করুন</option>
    @foreach ($categories as $category)
        <option value="{{ $category->id }}" {{ old('category_id') == $category->id ? 'selected' : '' }}>
            {{ $category->name }}
        </option>
    @endforeach
</select>

@error('category_id')
    <span class="text-danger">{{ $message }}</span>
@enderror

```

### **২. পোস্ট স্ট্যাটাস ডাইনামিক সিলেক্ট (`Draft`, `Published`, `Archived`)**

পোস্টের জন্য ৩টি নির্দিষ্ট স্ট্যাটাসের ডায়নামিক কন্ডিশনাল লজিক বসানো হয়েছে:

```blade
<select name="status" class="form-control @error('status') is-invalid @enderror">
    <option value="draft" {{ old('status') == 'draft' ? 'selected' : '' }}>Draft</option>
    <option value="published" {{ old('status') == 'published' ? 'selected' : '' }}>Published</option>
    <option value="archived" {{ old('status') == 'archived' ? 'selected' : '' }}>Archived</option>
</select>

```

### **৩. ট্যাগ সমূহের চেকবক্স মাল্টিপল সিলেকশন (`tags[]`)**

একটি পোস্টে একাধিক ট্যাগ নির্বাচন করার জন্য চেকবক্স অ্যারে `tags[]` তৈরি করা হয়েছে:

* **`in_array` ব্যবহার:** রি-সাবমিশনের সময় পূর্বে চেক করা ট্যাগগুলো নির্বাচন রাখতে PHP-এর `in_array()` হেলপার ব্যবহার করা হয়েছে।



```blade
@foreach ($tags as $tag)
    <label class="form-check-label me-3">
        <input type="checkbox" name="tags[]" value="{{ $tag->id }}" 
            {{ in_array($tag->id, old('tags', [])) ? 'checked' : '' }} class="form-check-input">
        {{ $tag->name }}
    </label>
@endforeach

```

### **৪. ফাইল আপলোডের গুরুত্বপূর্ণ কনফিগারেশন (`enctype`)**

ফর্মে ফাইল বা ফিচারড ইমেজ সাবমিট করতে ফর্ম ট্যাগে `enctype="multipart/form-data"` যুক্ত করতে হয়।

* **জরুরি বিষয়:** যদি এই অ্যাট্রিবিউটটি না দেয়া হয়, তবে লারাভেল বা পিএইচপি কোনো এরর দেবে না, কিন্তু ডাটাবেজ বা সার্ভারে সাইলেন্টলি ইমেজ ফাইলটি আপলোড হতে ব্যর্থ হবে।



```blade
<form action="{{ route('admin.posts.store') }}" method="POST" enctype="multipart/form-data">
    @csrf

    <!-- Featured Image Field -->
    <div class="mb-3">
        <label for="featured_image">ফিচারড ইমেজ</label>
        <input type="file" name="featured_image" accept="image/*" class="form-control">
        @error('featured_image')
            <span class="text-danger">{{ $message }}</span>
        @enderror
    </div>
</form>

```

### **৫. ফিচারড ও এডিটরস চয়েস চেকবক্স ফ্ল্যাগ**

পোস্টটি ফিচারড বা এডিটরস চয়েস কিনা তা ট্র্যাক করার জন্য বুলিয়ান ভ্যালু (`1`) পাস করা হয়েছে:

```blade
<!-- Is Featured Toggle -->
<input type="checkbox" name="is_featured" value="1" {{ old('is_featured') ? 'checked' : '' }}>

<!-- Is Editor's Choice Toggle -->
<input type="checkbox" name="is_editors_choice" value="1" {{ old('is_editors_choice') ? 'checked' : '' }}>

```

### **৬. স্টোর মেথডে সাবমিটেড ডাটা টেস্ট করা (`PostController.php`)**

ফর্মে সাবমিট করা ডাটা কন্ট্রোলারে সঠিকভাবে আসছে কিনা তা পরীক্ষার জন্য `dd($request->all())` প্রয়োগ করে চেক করা হয়েছে:

```php
public function store(Request $request)
{
    // Form input testing
    dd($request->all());
}

```

**টেকনিক্যাল টিপস**

* **Array Input Handling:** একাধিক চেকবক্স ইনপুট নেওয়ার জন্য নেম প্রোপার্টিতে অবশ্যই ব্র্যাকেট `tags[]` সংকেত ব্যবহার করতে হবে।


* **Old Array Fallback:** `old('tags', [])` ব্যবহারের সুবিধা হলো—যদি কোনো ডাটা সাবমিট না করা হয়, তবে একটি খালি অ্যারে ডিফল্ট ধরে নিয়ে `in_array()` ফাংশনের এরর প্রতিরোধ করবে।



আজকের ক্লাসে আমরা ফর্মে ক্যাটাগরি, ট্যাগ, ইমেজ ও বিশেষ ফ্ল্যাগসমূহ সঠিকভাবে কনফিগার করে কন্ট্রোলার পর্যন্ত পৌঁছানো সফলভাবে নিশ্চিত করেছি। পরবর্তী ক্লাসে আমরা এই প্রাপ্ত ইনপুট ডাটা ফিল্ডসমূহ লারাভেল ভ্যালিডেশন রুলসের অধীনে প্রসেস করে চূড়ান্ত ডাটাবেজ সেভ করার লজিক লিখব।
