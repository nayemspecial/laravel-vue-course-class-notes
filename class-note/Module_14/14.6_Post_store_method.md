প্রিয় শিক্ষার্থীবৃন্দ,

আজকের ক্লাসে আপনাদের সবাইকে স্বাগতম! গত পর্বে আমরা পোস্ট ক্রিয়েশনের ফর্ম কনফিগারেশন সম্পন্ন করেছিলাম।

আজকের পর্বে আমরা **লারাভেলের `PostController`-এর `store()` মেথডে রিকোয়েস্ট ভ্যালিডেশন, অটো-স্লাগ জেনারেশন, ফাইল আপলোড এবং মেনি-টু-মেনি রিলেশনশিপ (Pivot Table Syncing) এর মাধ্যমে পোস্ট ডাটাবেজে সংরক্ষণ** করার প্রক্রিয়াটি বিস্তারিত শিখব।

আজকের ক্লাসের বিস্তারিত লেকচার নোট নিচে উপস্থাপন করা হলো:

---

### **১. রিকোয়েস্ট ইনপুট ভ্যালিডেশন কনফিগারেশন (`$request->validate`)**

ডাটাবেজে পোস্ট ডাটা সংরক্ষণের আগে নিরাপত্তামূলক ডাটা চেক করার জন্য লারাভেলের ভ্যালিডেশন নিয়মাবলী প্রয়োগ করা হয়েছে:

* **টাইটেল, এক্সার্প্ট ও কন্টেন্ট:** টাইটেল বাধ্যতামূলক (`required`), এক্সার্প্ট ঐচ্ছিক (`nullable`) এবং কন্টেন্ট টেক্সট হিসেবে বাধ্যতামূলক করা হয়েছে।


* **ক্যাটাগরি আইডি:** ডাটাটি রিলেশনশিপ টেবিল থেকে আসছে কিনা নিশ্চিত করতে `exists:categories,id` রুল ব্যবহার করা হয়েছে।


* **স্ট্যাটাস:** সিলেক্টেড ভ্যালুটি যেন `draft`, `published`, অথবা `archived`-এর মধ্যেই সীমাবদ্ধ থাকে।


* **ট্যাগস (অ্যারে ইনপুট):** মাল্টিপল সিলেকশনের জন্য `tags` ফিল্ডটি অ্যারে আকারে নির্দিষ্ট করে `tags.*` দিয়ে আইডি অস্তিত্ব পরীক্ষা করা হয়েছে।


* **ফিচারড ইমেজ:** ইমেজ ফাইল এবং এর সাইজ সর্বোচ্চ `2MB` (`2048 KB`) সীমা নির্ধারণ করা হয়েছে।



```php
$validatedData = $request->validate([
    'title'          => 'required|string|max:255',
    'excerpt'        => 'nullable|string|max:500',
    'content'        => 'required|string',
    'category_id'    => 'required|exists:categories,id',
    'status'         => 'required|in:draft,published,archived',
    'tags'           => 'nullable|array',
    'tags.*'         => 'exists:tags,id',
    'featured_image' => 'nullable|image|max:2048',
]);

```

### **২. অটো-স্লাগ তৈরি ও ওনারশিপ নির্ধারণ**

ডাটাবেজে পাঠানোর আগে সংগৃহীত ভ্যালিডেটেড ডাটার ওপর অতিরিক্ত লজিক্যাল ডাটা যোগ করা হয়েছে:

* **`Str::slug()` ব্যবহার:** পোস্টের টাইটেল থেকে ইউআরএল-বান্ধব স্লাগ তৈরি করতে লারাভেলের `Illuminate\Support\Str` হেলপার ফেসাদ ব্যবহার করা হয়েছে।


* **ইউজার আইডি (Auth):** বর্তমানে লগইন অবস্থায় থাকা ইউজারের আইডি পেতে `Auth::id()` বা `auth()->id()` ব্যবহার করা হয়েছে।


* **বুলিয়ান ইনপুট:** ফ্ল্যাগ ফিল্ডসমূহ রূপান্তর করতে `$request->boolean()` প্রয়োগ করা হয়েছে।


* **পাবলিশড তারিখ সেট:** স্ট্যাটাস `published` হলে বর্তমান সময় (`now()`) অন্যথায় `null` নির্ধারণ করা হয়েছে।



```php
use Illuminate\Support\Str;

$data = [
    'title'             => $validatedData['title'],
    'slug'              => Str::slug($validatedData['title']),
    'excerpt'           => $validatedData['excerpt'] ?? null,
    'content'           => $validatedData['content'],
    'user_id'           => auth()->id(),
    'category_id'       => $validatedData['category_id'],
    'status'            => $validatedData['status'],
    'is_featured'       => $request->boolean('is_featured'),
    'is_editors_choice' => $request->boolean('is_editors_choice'),
    'published_at'      => $validatedData['status'] === 'published' ? now() : null,
];

```

### **৩. ফাইল আপলোড হ্যান্ডলিং (`featured_image`)**

ইনপুট ফর্মে ইমেজ সাবমিট করা হলে সেটি লোকাল স্টোরেজে সংরক্ষণ এবং ডাটাবেজ কলামে পাথ বসানোর লজিক যুক্ত করা হয়েছে:

```php
if ($request->hasFile('featured_image')) {
    $data['featured_image'] = $request->file('featured_image')->store('posts', 'public');
}

```

### **৪. ডাটা ক্রিয়েশন ও পিভট টেবিল সিঙ্কিং (`sync`)**

পোস্ট অবজেক্ট তৈরি শেষে মেনি-টু-মেনি রিলেশনশিপের ডাটা সংরক্ষণের পদ্ধতি প্রয়োগ করা হয়েছে:

* **`sync()` મેથડ:** পিভট (Pivot) টেবিলে ট্যাগ আইডিগুলো সঠিকভাবে ম্যাপ করতে লারাভেলের `$post->tags()->sync()` ব্যবহার করা হয়েছে, যাতে ডুপ্লিকেট ভ্যালু তৈরি না হয়ে অটোমেটিক অ্যাটাচমেন্ট সম্পন্ন হয়।



```php
// Post Model Creation
$post = Post::create($data);

// Many-to-Many Pivot Table Syncing
$post->tags()->sync($validatedData['tags'] ?? []);

```

### **৫. রিডাইরেকশন ও ফ্লাশ মেসেজ শো**

পোস্ট ডাটাবেজে সফলভাবে সংরক্ষণ হলে ব্যবহারকারীকে ইনডেক্স লিস্টে ফেরত পাঠিয়ে একটি সাকসেস মেসেজ ফ্লাশ করা হয়েছে:

```php
return redirect()->route('admin.posts.index')
                 ->with('success', 'পোস্ট সফলভাবে তৈরি হয়েছে।');

```

---

**টেকনিক্যাল টিপস**

* **`Str::slug` ফেসাদ ইম্পোর্ট:** কন্ট্রোলারের একদম উপরে `use Illuminate\Support\Str;` ডিক্লেয়ার করা না থাকলে রানটাইম এরর তৈরি হবে।


* **`sync()` এর সুবিধা:** মেনি-টু-মেনি রিলেশনশিপের ক্ষেত্রে `attach()` ব্যবহার করলে বারবার সাবমিট করলে একই আইডি বারবার যুক্ত হওয়ার ভয় থাকে; কিন্তু `sync()` পুরানো রেকর্ড পরিষ্কার করে সঠিক সেটটি আপডেট করে দেয়।


* **`store()` ডিস্ক স্পেসিফিকেশন:** পাবলিকলি ছবি অ্যাক্সেস করতে ফাইল আপলোডে `'public'` স্টোরেজ ডিস্ক উল্লেখ রাখা প্রয়োজন।



আজকের ক্লাসে আমরা ডাটাবেজে ডাটা ভ্যালিডেশন থেকে শুরু করে অটো স্লাগ, ফাইল আপলোড এবং রিলেশনশিপের ট্যাগ সিঙ্ক সফলভাবে সম্পন্ন করেছি। পরবর্তী ক্লাসে আমরা এই সংরক্ষিত পোস্ট ডাটা টেবিল ভিউতে প্রদর্শন, শো মেথড ও এডিট/আপডেট লজিক নিয়ে আলোচনা করব।

আপনাদের কোনো প্রশ্ন থাকলে নিঃসঙ্কোচে করতে পারেন!
